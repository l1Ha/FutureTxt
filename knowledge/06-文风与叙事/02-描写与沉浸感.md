# 02 描写与沉浸感

## 1. 五感配比：打破"视觉独裁"

纯视觉描写是科幻最常见的扁平病（星舰只有灯光，异星只有颜色）。给每个重要场景做**感官配额**：

| 感官 | 科幻中的典型用法 | 示例方向 |
|---|---|---|
| 视觉 | 默认项，占 ≤50% | 光的质地、比例、运动 |
| 听觉 | 密闭空间最佳武器 | 金属冷缩声、循环风的固定频率、绝对安静 |
| 触觉/体感 | 失重、辐射、维生服内 | 漂浮时胃的上浮感、面罩结雾的湿气 |
| 嗅觉 | 最易唤起记忆与不安 | 臭氧、循环舱的金属味、异星大气的甜腥 |
| 味觉 | 低成本高奇效 | 口水变甜（缺氧）、配给食物的塑料味 |

**操作**：写完一个场景，统计感官种类；只有一种的，补两种，且**优先补听觉与嗅觉**。

## 2. 尺度感描写：把数字变成身体

巨型与微观是科幻的招牌，但直接甩数字（"直径十万公里"）读者无感。四种锚定法：

1. **熟物对比**：把新尺度贴在读者身体上——"它的一块装甲板能把整座体育场扣进去"。
2. **过程耗时**：用移动/扫描所需时间表达尺度——"光走完它的外壳用了两秒"。
3. **局部代整体**：只写一角，让读者自行放大——"我们只看到了它的一个起落架阴影，天就黑了。"
4. **管理尺度**：写这个尺度带来的行政、物流、时间成本——管理一百万人比描写一百万人更显其大。

**反例禁用**："大到无法想象""难以形容的巨物"——这类词是描写的弃权。

## 3. 陌生意象的可感化：陌生 + 熟悉公式

陌生事物 = 一个读者没见过的特征 + 一个读者身体记住的参照。

- ❌ "这是一种硅基的多面体生物。"（纯名词）
- ✅ "它移动时像一把湿伞被风翻过来，关节发出拉开行李箱拉链的声音。"

**三步法**：
1. 先给**动作**（它在做什么），再给**质感**（硬/软/黏/脆），最后才给**名字**。
2. 用身体参照系：拇指、心跳、一步、呼吸、体温。
3. 每个陌生意象指定**一个贯穿全书的稳定比喻**，不要每章换喻体（读者需要锚点）。

## 4. 避免名词轰炸

**名词轰炸**：一句里堆 3 个以上新术语/新专名，读者当场弃书。

治理规则：
1. **每句只引入 1 个新名词**，且本段内不再引入第二个。
2. **新名词后必须紧跟一个动词或一个效果**："量子织布机启动了"优于"量子织布机是采用量子纠缠的织造装置"。
3. **术语要动词化使用**：让人物去"跃迁""烧穿""冻结记忆"，而不是讨论这些词的定义。
4. **首现打星号或括注的冲动要忍住**：能用上下文猜到的，绝不加注。
5. 同一段里若已有 2 个新概念，第三个改用普通词描述。

**自检句**：把段落里的所有专有名词涂黑，剩下的句子如果读不通、无动作、无情结，说明你是靠名词在撑场面。

## 5. 描写的功能性：每段描写必须完成至少一项任务

- 推进目标（这个环境是障碍还是工具）
- 暗示威胁（下文会用到的危险提前露头）
- 表达人物心境（投射，而非客观测绘）
- 埋设伏笔（后续要回收的细节）
- 确立基调（科幻类型的气味）

**一项都不完成的描写，删。** 描写不是暂停叙事，是叙事的另一种推进方式。

**篇幅纪律**：动作章中的描写段 ≤3 行；喘息章可以放开到 8–10 行。描写长度应与当章节奏成反比。

## 6. 实操清单

1. 建立本书的"感官词库"：每种感官列 10 个可复用短语，写场景时对表勾选。
2. 每个主要场景写完做两项统计：感官种类数、新名词数（分别要求 ≥3 种、≤3 个）。
3. 把所有"直径/质量/数量"数字旁补一句身体锚定。
4. 给全书三大陌生意象各定一个固定比喻，写入设定文档，全书不换。
5. 搜索"巨大""无法想象""难以形容"等弃权词，逐个替换成具体对比。
6. 逐段检查：涂黑专名后仍须有动作与情绪。
7. 读出声：描写段拗口处通常是名词堆叠，改成动词短句。

## 本篇要点速查

- 视觉 ≤50%，主动补听觉与嗅觉，五感配额化管理。
- 尺度用熟物对比、过程耗时、局部代整体、管理成本四种方法锚定，禁止"大到无法想象"。
- 陌生意象 = 陌生特征 + 身体参照；先动作、再质感、最后才命名。
- 每句只引入 1 个新名词，紧跟动词或效果，术语优先动词化。
- 每段描写至少完成推进/威胁/心境/伏笔/基调中的一项，否则删。
- 描写长度与节奏成反比：高潮章 ≤3 行，呼吸章可放开。
- 给关键意象定一个贯穿全书的固定比喻，别每章换喻体。
