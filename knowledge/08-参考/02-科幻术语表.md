# 科幻术语表

类型词与工艺词混编，供引用与审稿对齐。三栏：术语、定义、用途。

## 类型与题材

| 术语 | 一句定义 | 写作用途 |
|---|---|---|
| 硬科幻 | 物理、工程推演为核心 | 用技术难题驱动情节 |
| 软科幻 | 重心在社会与心理 | 直接探讨观念 |
| 太空歌剧 | 银河冒险与帝国舰队 | 追求宏大场面 |
| 军事科幻 | 战术编制与战争伦理 | 写战斗与指挥博弈 |
| 社会科幻 | 拿制度、阶级当变量 | 检验现实议题 |
| 反乌托邦 | 表面完美、内在压迫 | 快速建立反抗动机 |
| 废土 | 崩溃后的荒芜生存 | 补给装备即情节 |
| 赛博朋克 | 高科技低生活都市 | 阶层落差与身体改造 |
| 生态朋克 ecopunk | 生态修复技术为核心 | 正面写人与环境共生 |
| 第一次接触 | 与外星文明相遇 | 认知鸿沟生出恐惧 |

## 结构与写作工艺

| 术语 | 一句定义 | 写作用途 |
|---|---|---|
| Infodump | 一次性大段说明设定 | 拆进冲突勿断节奏 |
| Techsplain | 借角色之口解说技术 | 让解释带上立场 |
| Technobabble | 显得专业的术语堆砌 | 只点缀氛围勿藏关键 |
| 硬转折 | 靠新设定强行推进 | 改写为选择驱动 |
| Mary Sue | 无缺点无代价的主角 | 检查代价是否对等 |
| Gibberish 科学黑话 | 半真半假的伪科学句 | 用作纹理不作论据 |
| MacGuffin | 人人追逐的不重要目标 | 给情节可争夺的实体 |
| 契诃夫之枪 | 先出场的要素后必有用 | 回收伏笔的判据 |
| 冷开场 | 正片前的钩子场景 | 首段抓住读者 |
| 章末钩子 | 章节结尾的悬念 | 提升翻页率 |
| 悬念收尾 | 危机顶点切断章节 | 控制频率防疲劳 |
| 三幕式 | 设定、对抗、解决 | 稳妥的初稿骨架 |
| 中点反转 | 全书一半处认知翻转 | 重新设定赌注 |
| 低谷时刻 | 主角失去方向与资源 | 为高潮蓄力 |
| 英雄之旅 | 出发、启蒙、回归 | 类型小说模板 |
| 群像剧 | 多视角轮流推进 | 切换时给读者定位 |
| 双线交织 | 两条时空线对照 | 并置生出主题回声 |
| 不可靠叙述者 | 记忆或立场有偏 | 文内埋可验证裂缝 |
| 视角人物 POV | 全书跟随的观察眼 | 一章内不随意换眼 |
| 展示而非陈述 | 用动作细节代替结论 | 感染力的基本功 |
| 时间悖论 | 时间旅行的因果冲突 | 先定规则再写代价 |
| 自举悖论 | 物与信息循环无起源 | 写宿命感的短篇利器 |
| 祖父悖论 | 改变祖先致自身消失 | 时间旅行的风险条款 |
| 机械降神 | 外力突然解决危机 | 高潮禁用的红旗 |

## 本篇要点速查

- 类型词决定读者预期，工艺词决定稿子能否改下去。
- 引用术语只取定义栏，写作建议不写进词条正文。
- Infodump、Techsplain、硬转折是三个常见审稿红旗。
- 契诃夫之枪要求回收，机械降神禁止突降。
- 硬科幻概念先写限制条件，再写能力。
- 时间类悖论先立法，违规必付代价。
