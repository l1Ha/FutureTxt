# 审稿自查清单

流水线审校阶段的引用文件。逐板块勾选，「否」或「拿不准」登记到问题表，交稿前清零。每条均可判定。

## 世界观一致性

- [ ] 开篇定下的硬规则，全书至少有一次被遵守的实例吗？
- [ ] 各章的政府、货币、交通是否指向同一个世界？
- [ ] 角色说出只有读者才知道的设定，他凭什么知道？
- [ ] 新设定能否用前文规则解释，还是临时补丁？
- [ ] 地点与季节是否连贯（上章沙漠，下章雨林）？
- [ ] 世界规则是否沦为随时救场的工具，冲突还有约束吗？

## 科学可信度

- [ ] 关键技术首现是否写清能耗、时延、故障率？
- [ ] 超光速或时间旅行的规则全书只有一版吗？
- [ ] 删掉术语后，那段科学解释的逻辑还成立吗？
- [ ] 真空、辐射下的身体反应是否被浪漫化？
- [ ] 有无「三天建成戴森球」式的数量级错误？
- [ ] 有无为情节临时发明的万能材料或病毒？

## 人物动机

- [ ] 主角第十章的决定，能否回溯到第二章的欲望？
- [ ] 反派的目标在其自身立场内是否合理？
- [ ] 生死关头的选择，付出的代价是否对等？
- [ ] 有无角色只为让读者知道设定而开口？
- [ ] 感情转折有无事件支撑，还是只靠一次对视？
- [ ] 主角学会的三件事，能在正文里逐条指出来吗？

## 结构节奏

- [ ] 全书约五成处的中点有认知翻转吗？
- [ ] 有无连续三章都是赶路、开会、训练？
- [ ] 高潮依赖的能力或道具，前面出现并练过吗？
- [ ] 有无删掉后情节不受影响的章节？
- [ ] 时间跨度最大的一跳补足交代了吗？
- [ ] 结局之后还挂着未兑现的钩子或支线吗？

## 章节钩子

- [ ] 每章最后两句能独立作下一段引子吗？
- [ ] 钩子是新问题，还是重复上章的旧危机？
- [ ] 有无连续两章以同样方式（爆炸、电话）收尾？
- [ ] 悬念在三章内兑现了吗，还是无限拖欠？
- [ ] 中段章节的钩子弱于前三章吗？
- [ ] 有无某章开头超过二百字才进入正题？

## 文风与视角

- [ ] 全书是否只有一双眼睛，换视角处有空行标记吗？
- [ ] 叙述时态（过去／现在）全书统一吗？
- [ ] 有无超出视角人物感知的信息（不在场知其心情）？
- [ ] 比喻是否全来自同一喻体库（清一色军事或美食）？
- [ ] 有无某几段形容词陡增、节奏塌陷？
- [ ] 首段与末段的语气像同一个人写的吗？

## 对话

- [ ] 删掉说话人标签，还能分辨谁在说吗？
- [ ] 有无两个角色互相解释彼此都知道的背景？
- [ ] 每段对话有潜台词吗，还是纯信息搬运？
- [ ] 未来人说话是否被统一写成某种复古腔？
- [ ] 有无超过五行、无人打断的长台词？
- [ ] 争吵时每人都是完整句，缺少抢白与沉默？

## 信息释放

- [ ] 读者首次接触核心设定，早于它变重要吗？
- [ ] 有无超过半页的连续说明段？
- [ ] 自造词首现时有场景托底吗，还是直接定义？
- [ ] 悬念答案公布前，埋过可推断的线索吗？
- [ ] 同一设定是否被解释了三次？
- [ ] 高潮前十个百分点内还在倾倒新设定吗？

## 术语统一性

- [ ] 同一组织、星球、技术全书只用一个名称吗？
- [ ] 自造词的大小写、译名、缩写前后一致吗？
- [ ] 术语表覆盖正文全部自造词了吗？
- [ ] 中英文空格、引号、单位全书统一吗？
- [ ] 有无残留改名前的旧称？
- [ ] 数字写法在同一语境下一致吗？

## 敏感与刻板印象

- [ ] 反派或愚昧群体的标签总落在同一性别、族裔吗？
- [ ] 身体改造或疾病是否被写成道德缺陷的隐喻？
- [ ] 未来权力结构是否原样复制了现实歧视？
- [ ] 异族名词只是装饰吗，有无该群体的内部视角？
- [ ] 性别角色互换后情节仍成立吗？不成立，理由够吗？
- [ ] 弱势角色有无超出工具人的欲望与结局？

## 连贯性（时间线／人物状态／物品位置）

- [ ] 列出全部日期与星期，有无两个事件同一时刻？
- [ ] 主角的伤、服装、补给随章节如实演化了吗？
- [ ] 关键道具最后的位置与高潮时一致吗？
- [ ] 同一人物的年龄、口音、称呼前后一致吗？
- [ ] 航行、监禁期间外部变化与耗时匹配吗？
- [ ] 上章在场的人物，这章无理由消失了吗？

## 终稿格式

- [ ] 章节编号与标题格式全书统一吗？
- [ ] 有无残留修订标记、批注、重复段落、占位符？
- [ ] 引号、破折号、省略号是同一套全角符号吗？
- [ ] 空段、双空格、行首空格清理干净了吗？
- [ ] 人名初次全名与后续简称规则统一吗？
- [ ] 交稿字数落在合同要求区间内了吗？

## 本篇要点速查

- 先扫连贯性与术语统一性，这两类问题最多、最易批量修。
- 科学可信度只看限制条件，不看名词是否高级。
- 人物动机的判据是可回溯：决定能指向前文的代价。
- 结构抓三处：中点、高潮装备、可删章节。
- 钩子与信息释放一起查：先看欠了什么账，再看是否三章归还。
- 敏感项按「标签是否总落在同一群体」机械检查，比凭感觉可靠。
- 格式问题留到最后统一处理，避免与内容修改互相覆盖。
