# 03 生物学、进化与生态

本篇给外星生物、生态圈与进化叙事提供**合规素材**，核心原则：进化没有目的，生态必须有能量账。

## 一、可用设定素材

### 1. 进化机制：可写的四种动力

| 机制 | 内核 | 叙事用法 |
|---|---|---|
| 自然选择 | 变异+遗传+差异繁殖，**无方向无目的** | "适应"不等于"进步"，可写退化 |
| 遗传漂变 | 小种群中随机丢失基因 | 封闭殖民地的创始人效应、近亲衰退 |
| 中性进化 | 大量突变与选择无关，随机固定 | 解释"看起来像设计其实偶然" |
| 表观遗传/可塑性 | 环境开关基因表达，可部分遗传 | 几代人内就变的"太空一代" |

- **时间尺度感**：微生物/人工选育可在数十代内剧变；复杂新器官通常需要百万年——**想写"百年进化出新器官"必须靠人工选择或基因编辑**。
- **进化常被误读为阶梯**：实际上更像灌木丛，大量分支灭绝，"高等/低等"是人类偏见。可利用：角色坚信进步史观，被生态事实打脸。
- **寄生与共生**是进化最强的推手之一：线粒体本是被吞噬的细菌（内共生），这给了"细胞器级合作"叙事依据。

### 2. 趋同进化：外星生物"眼熟又陌生"的钥匙

不同祖先为解决同一问题，演化出相似结构：

- 鲨鱼（鱼）、海豚（哺乳）、鱼龙（爬行）→ 流线型身体。
- 翅膀独立演化出多次；眼睛进化出数十次。
- **创作公式**：外形熟悉（提供可读性）+ 生化/感官陌生（提供惊奇）= 既可信又新鲜的外星生物。

### 3. 生态系统：能量流决定一切

- **能量金字塔**：营养级之间约只有 10% 能量传递 → 食物链极少超过 4–5 环 → 顶级掠食者数量必然稀少。
- **关键种**：去除一个物种可致整个系统崩溃（海獭→海胆→海藻林）。
- **演替**：火山岛/灭世后从先锋地衣到顶极群落，需要数百年——可写"重建百年仍只有苔藓"的荒凉。
- **r/K 策略**：r 型（多产、早死、赌运气）适合虫群式威胁；K 型（少产、长养、重竞争）适合文明物种。
- **生物量与初级生产力**：决定一颗星球能养多少人、多少城市。

### 4. 外星生物学（天体生物学素材）

| 议题 | 可用设定 | 限制条件 |
|---|---|---|
| 碳基生命 | 碳-碳可成长链，常温化学丰富 | 几乎所有已知生命 |
| 硅基生命 | 硅-氧键耐高温 | 常温下难形成长链、代谢产物是固体岩石 |
| 溶剂 | 水（极性、抗冻）；氨（−78℃仍液态）；甲烷（土卫六） | 溶剂决定代谢速率与体温 |
| 极端环境 | 嗜极生物：深海热泉、高盐、强辐射、无氧 | 地球生命上限约 121℃；硫化氢泉可成独立食物网 |
| 生命定义 | 代谢、复制、自组织——**尚无共识** | 让角色争论定义，比直接宣布更真实 |
| 感官体系 | 无光世界→回声定位/电感；高压暗海→化学感应 | 感官决定语言与艺术形态 |

**可用推论链**：溶剂与温度 → 代谢速率 → 寿命与繁殖策略 → 社会结构；能量来源（光合/化能/捕食）→ 是否定居 → 是否发展农业 → 是否有"文明时间表"。

## 二、常见科学错误

| # | 错误写法 | 问题 | 修复 |
|---|---|---|---|
| 1 | 进化"为了生存而长出某器官" | 进化无目的 | 改为"有该变异者偶然留下更多后代" |
| 2 | 三米高的巨兽靠几根细腿行走 | 体型受平方-立方律限制 | 增粗肢体/水浮力/低重力 |
| 3 | 外星怪兽呼吸氧气又同时厌氧 | 代谢矛盾 | 选定一种能量代谢路径 |
| 4 | 单一作物/单一食物链星球 | 生态极脆弱 | 至少三层：生产者、分解者、关键种 |
| 5 | 地球生物换皮就当外星生物 | 缺乏生化差异 | 至少改一项：溶剂、色素、感官、遗传物质 |
| 6 | 荒凉星球上到处是绿植 | 初级生产力需要能量源 | 先写清能量来源（恒星光照/化学能） |
| 7 | 进化在故事时间尺度内完成 | 复杂性状需百万年 | 用人工选择、基因驱动或微生物代次 |

## 三、写作时如何解释或规避

**能量预算法**：任何生物出场前先答三问——吃什么？多久吃一次？没有它会怎样？答不出就不该写它上场。

**物理约束法**：体型、速度、感官先过物理关（重力、大气密度、含氧量、平方-立方律），再谈外形美感。

**生态位解释行为**：行为不是"性格"，是生态位的答案。夜行、群居、拟态、迁移——都能从天敌与食物反推。给外星生物一个**生态位说明书**，角色的解读就有了依据。

**把科学争议写成争论**：让生物学家与宇航员对"这算不算生命"各执一词——既自然地解释概念，又暴露人物立场（谁想开枪、谁想研究、谁想带回去卖）。

**惊奇的落差结构**：先给熟悉的类比（"像章鱼"），再揭示关键差异（"但它的神经节分布在外套膜上，痛觉是全向的"），最后让差异**伤害角色**——理解必须带来代价。

## 四、实操清单

1. 为每个外星物种填表：**溶剂/能量来源/食谱/繁殖策略/天敌/感官/生态位**。
2. 画出目标星球的**食物网**（至少生产者、初级消费者、顶级消费者、分解者四层）。
3. 检查体型是否通过**平方-立方律与重力**验算（可用 1.5 倍体重→四肢粗细的直觉核对）。
4. 明确**进化时间线**：自然发生 / 人工设计 / 外来播种，三选一并全程一致。
5. 给至少一个物种安排**趋同进化梗**：外形眼熟、内里陌生。
6. 为"这算生命吗"准备**两种对立定义**，分配给立场不同的角色。

## 本篇要点速查

- 进化**无目的、无方向**，写"适应"别写"追求"。
- 时间尺度是硬约束：复杂性状需**百万年**，微生物与人工选育可快。
- **趋同进化**是外星生物设计公式：外形熟悉 + 生化陌生。
- 生态先算**能量账**：10% 传递律决定食物链短、顶级掠食者稀少。
- 碳基可靠、硅基需**高温且代谢产固体**；溶剂决定体温、代谢与寿命。
- 行为用**生态位**解释，比贴性格标签更可信。
- 科学争议交给**角色争论**，同时暴露人物立场。
