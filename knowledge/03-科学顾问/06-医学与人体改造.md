# 06 医学与人体改造

本篇覆盖人体冷冻、脑机接口、基因编辑、义体化与太空医学。核心原则：**身体是有账本的，每次改造都要付恢复、排异与伦理三笔账。**

## 一、可用设定素材

### 1. 人体冷冻

| 环节 | 科学要点 | 可写的剧情风险 |
|---|---|---|
| 保存前 | 心肺停止即开始缺氧，须立刻玻璃化 | 谁有权签字、延误即脑损伤 |
| 玻璃化 | 用冷冻保护剂置换水分，避免冰晶刺破细胞 | 保护剂本身有毒，冲洗是鬼门关 |
| 复温 | 快速均匀复温，慢了会重结晶 | 设备故障=解冻即死 |
| 苏醒后 | 肌萎缩、骨流失、神经重塑 | 数月康复，记忆与法律身份断裂 |

**叙事富矿**：冷冻是**单向的时间袋**——债主、通缉令、绝症、爱人全冻结在门外；醒来即"社会性死亡再复活"。争议点：冷冻算治疗还是死亡？苏醒谁来批？

### 2. 脑机接口（BCI）

- **分级谱系**：非侵入（EEG，带宽低、信号糊）→ 半侵入（皮层表面）→ 深部植入（带宽高、需开颅）。
- **带宽即体验上限**：读运动意图（意念打字、机械臂）已实现；读"看见了什么词"很难，读复杂思想与画面远未做到。
- **渐进解码**：信号是统计推断，会漂移，需每日校准——"越用越准"与"越用越乱"都可写。
- **风险池**：感染、瘢痕包埋（信号逐年衰减）、电极移位、癫痫，以及**读取即审讯、改写即洗脑**。
- **伦理无先例**：思想隐私、脑数据归属、被植入者的责任能力与公民资格。

### 3. 基因编辑

- **CRISPR 类工具**：向导 RNA 定位 + 核酸酶切割 → 细胞自行修复（常出错）；**脱靶→癌变风险**，一次改多基因更危险。
- **多基因性状**：身高、智力、性格由成百上千基因与环境共同决定，**"一个开关一个特征"是最常见的科幻错**。
- **四条路径**：体细胞编辑（不遗传，争议小）→ 生殖系编辑（可遗传，"设计婴儿"）→ 基因驱动（强制扩散整个种群）→ 表观开关（环境触发，休眠基因在太空醒来）。
- **必然不完美**：嵌合体（部分细胞改了）、联动性状（改肌肉也改心肌）、几代后才显形的代价——**用不完美换可信度**。

### 4. 义体化

| 主题 | 可用素材 | 戏剧点 |
|---|---|---|
| 神经接口 | 双向反馈、需学习期 | 新手期笨拙、幻肢感、高手成瘾 |
| 排异与免疫 | 异物包囊、慢性炎症、终身服药 | **药=身份的持续许可**，停药即废 |
| 能源与维护 | 电池日充、月检、备件昂贵 | 断电、零件被锁、厂家远程停机 |
| 阶级分化 | 富人原生器官，穷人二手货 | 分期付款的肢体、器官租借 |
| 心理 | 身体图式错乱、过度升级 | "还有多少是我自己" |

**必写的现实项**：疼痛、散热、接口清洁、更新失败——**改造人依然要吃饭、上厕所、保养**。

### 5. 太空医学

- **生理衰减**：失重下骨流失约 1%/月、肌肉萎缩、体液上涌→颅内压升高→**视神经压迫（SANS，宇航员视力永久下降）**。
- **辐射**：无磁场屏蔽则癌症率上升，**深空任务终身剂量有上限**，可直接做成任务配额。
- **人工重力副作用**：旋转结构的**科氏效应**让人一站起就晕，必须写适应期或限制头部运动。
- **心理与卫生**：隔离、无隐私、通信延迟、**"地平线效应"**（长期封闭后道德感下降）；废水回收、霉菌与体味。
- **分娩与药物**：低重力下胎儿发育未知，殖民地婴儿是高风险政治事件；地面剂量在此可能过量或失效。

## 二、常见科学错误

| # | 错误写法 | 问题 | 修复 |
|---|---|---|---|
| 1 | 换义体像换衣服 | 手术、神经接合、康复期都要时间 | 写数周训练与疼痛 |
| 2 | 基因"一个开关一个特征" | 性状多基因+环境 | 写联动性状与脱靶 |
| 3 | 冬眠=普通睡一觉 | 代谢抑制≠无损 | 加复苏失败率与肌骨康复 |
| 4 | 改造后无排异无感染 | 异物反应客观存在 | 给终身药物与随访 |
| 5 | 脑机一接就全知 | 带宽与校准有限 | 写学习期、漂移、误读 |
| 6 | 太空船上无疾病无心理问题 | 密闭与延迟放大问题 | 写卫生、霉菌、隔离反应 |
| 7 | 冷冻复苏者立刻适应社会 | 身份与法律断裂 | 写档案、语言、财产纠纷 |

## 三、写作时如何解释或规避

**医疗资源三问**（每场戏先答）：**谁出钱、药从哪来、断了怎么办。** 未来医疗的戏剧几乎全在这三问里，比技术本身更锋利。

**恢复期叙事法**：把改造后的**第一周 / 第一次 / 第一次失败**写成完整小节——恢复期天然产出依赖、暴露弱点、副作用登场。

**副作用即情节**：为每项技术列 2–3 个副作用，挑一个在关键节点发作（义体被厂商远程锁定、镇静剂在审讯时失效）。

**身体细节锚定**：接口要消毒、电池要充电、冷天义肢变迟钝、幻肢发痒——低成本细节比参数表更能建立可信度。

**伦理交给利益方**：保险公司、宗教团体、退伍军人协会、家长会——每个机构一句主张，解释概念的同时暴露利害。

## 四、实操清单

1. 每项医疗技术建卡：**原理一句话 / 恢复期 / 三个副作用 / 谁付钱 / 断供后果**。
2. 冻眠剧情必答：**谁批准、醒了找谁、钱还在吗、身体几成能用**。
3. 义体角色必配：**能源方案、维护地点、一种依赖服务、一个阶级标记**。
4. 写基因改造前先列**三个脱靶或联动后果**，避免"完美定制"。
5. 深空任务标注**累计辐射剂量与剩余配额**，做成硬性上限。
6. 给改造人保留**一件无法改造的原生部件**（味觉、旧伤），作为人性锚点。

## 本篇要点速查

- 身体是账本：**恢复期、排异、费用**三笔账一个都不能少。
- 冷冻=**单向时间袋**，苏醒的社会断裂比技术本身更出戏。
- 脑机的真相是**统计推断**：带宽有限、会漂移、可被劫持。
- 基因是**网不是开关**：多基因、脱靶、嵌合、延迟显形。
- 义体化的关键是**能源、备件、厂商权力与阶级**。
- 太空硬指标：**骨流失 1%/月、辐射剂量上限、科氏眩晕、地平线效应**。
- 医疗戏剧先问：**谁出钱、药从哪来、断了怎么办。**
