# 核心主题与思想实验（科幻的情节发动机）

## 一、思想实验是发动机，不是装饰

科幻最经济的结构：把一个哲学/科学问题**翻译成处境**，让角色在其中付代价。思想实验提供冲突，世界观提供舞台。判断一个设定是否值得写：它能否至少撑起下面清单中的一项实验。

## 二、八大思想实验：表述 → 小说化用法 → 陷阱

1. **技术奇点**
   - 表述：智能超越人类后，进步速度脱离人类理解。
   - 用法：写「前奇点」的最后一年——擦鞋匠、祭司、基金经理各自如何押注；或写奇点之后人类沦为宠物/遗产的失落感。
   - 陷阱：把奇点写成单纯升级；忽略过渡期的政治斗争与既得利益者阻挠。

2. **费米悖论（大过滤器 / 黑暗森林）**
   - 表述：宇宙这么老这么大，外星人在哪里？
   - 用法：给出你的「过滤器」位置（生命稀有？文明自毁？），并让主角团成为验证者；黑暗森林是一种**社会博弈解**：猜疑链 + 技术爆炸 + 资源有限 → 先手打击是理性策略。
   - 陷阱：把答案写成唯一真理；黑暗森林套用时忘记它依赖的三个前提是可以被打破的。

3. **忒修斯之船（身份同一性）**
   - 表述：部件全部更换后，它还是原来那个吗？
   - 用法：意识上传、记忆编辑、义体化、克隆——让**制度**先给出答案（财产、继承、婚姻是否承认新身体），再让角色感受后果。
   - 陷阱：只问「我还是我吗」，不问「别人是否仍这样对待我」。

4. **缸中之脑（现实与模拟）**
   - 表述：感官输入可被完全制造。
   - 用法：不写「揭穿幻觉」，写**选择留在幻觉中**的伦理；或写模拟世界的维护成本与断电风险。
   - 陷阱：用「原来是梦」收尾，浪费设定。

5. **时间悖论（祖父悖论 / 自洽循环）**
   - 表述：改变过去是否可能。
   - 用法：先锁死规则（可改/不可改/只有一次机会），再让角色为规则**承担信息不对称**；《信条》式交叠因果适合写责任与牺牲。
   - 陷阱：中途换规则；用旁白解释悖论而不让角色付出代价。

6. **电车难题的制度化（自主武器与对齐）**
   - 表述：谁为机器的杀戮决策负责。
   - 用法：把伦理难题变成**官僚流程**——谁签字、谁背锅、指标如何被钻空子。
   - 陷阱：用「邪恶AI」逃避责任链条。

7. **他心问题与他者**
   - 表述：我们无法直接验证另一个心智的存在。
   - 用法：外星人、宠物、婴儿、AI 是否拥有权利，取决于人类是否**愿意当它存在**。
   - 陷阱：让外星人太像人，问题自动消失。

8. **囚徒困境 / 公地悲剧**
   - 表述：个体理性导致集体灾难。
   - 用法：星际威慑、气候谈判、开源与垄断——重复博弈中背叛者如何被惩罚或反杀。
   - 陷阱：用「人类终将团结」一笔带过，取消了博弈张力。

## 三、方法论：从思想实验到情节的三步

1. **落位**：把抽象问题落到具体制度与身体（不是「意识能否上传」，而是「上传者是否有投票权」）。
2. **代价**：给每个答案安排支付者（有人获利、有人失业、有人被宣布为非人）。
3. **升级**：按三幕推进——个人代价 → 群体冲突 → 文明尺度的选择；每幕都是同一个问题的更大版本。

## 四、常见错误

1. 让角色口头辩论思想实验，而不是被卷入其处境。
2. 给出「正确答案」，取消读者的思考空间。
3. 一个设定塞五个问题，每个都浅。
4. 只有概念张力，没有人物欲望（读者记不住问题，只记住人）。
5. 把已有经典解法原样复述，没有当代变量（如今天的算力、气候、基因成本）。

## 五、实操清单

1. 用一句话写出本作的核心问题：「___ 到底是不是 ___？」
2. 把它落到 1 个制度 + 1 个身体/日常场景。
3. 列出三个立场及其代价承担者。
4. 规划三幕升级路径，每幕标注尺度（个人/群体/文明）。
5. 检查：删掉思想实验后故事是否塌陷。
6. 写 200 字「不给出的结局」，保持开放。

## 本篇要点速查

1. 思想实验 = 冲突源；先落位到制度与身体，再谈概念。
2. 每个答案都要有人付账，否则张力不存在。
3. 黑暗森林成立依赖猜疑链、技术爆炸、资源有限三前提。
4. 忒修斯问题的现代写法：先问制度承认谁，再问我是谁。
5. 悖论类先锁规则，全程不换，让角色承担信息差。
6. 三幕即同一问题的三级尺度升级。
7. 忌角色空谈、忌给出标准答案、忌一设定塞五问。
