# 世界观构建方法：自上而下的推演流程

## 一、核心原则：从一个「如果…会怎样」向下推

世界观不是名词库，而是**因果链**。正确的顺序是：先定一个与现实分手的假设，再逐层推演它造成的后果，最后才允许你描写风景。

自上而下五层（上层决定下层，禁止下层倒逼上层）：

1. **自然/物理层**：宇宙常数、资源分布、地理气候——哪些与地球相同？
2. **技术层**：哪个技术被发明、成本几何、由谁掌握？
3. **制度层**：法律、产权、暴力垄断、劳动组织如何响应？
4. **文化层**：信仰、价值观、审美、禁忌如何沉淀？
5. **日常层**：饮食、交通、问候、货币、垃圾、育儿——读者实际看到的表面。

示例链：*可控核聚变免费 → 电力近乎零成本 → 海水淡化与垂直农业普及 → 粮食与水不再稀缺 → 国家的税收基础从消费转向数据与轨道权 → 移民宣传话术改变 → 一句老谚语失效*。链条每往下一层，你就多一批可用细节。

## 二、冰山原则与暴露节奏

- 只写**会被情节使用的 20%**；其余留在设定圣经里备查。
- 暴露三原则：**首次出现时只给必要量**（一个功能 + 一个代价）、**分散注入**（每场戏最多一个新概念）、**由困惑到理解**（让角色和读者同时学）。
- 每个新概念必须绑定一个人物动作，禁止解说段落单飞。

## 三、一致性检验（推演后的三道审计）

1. **因果审计**：任选 3 个上层设定，各写下一条传导到日常层的具体后果；写不出来说明推演断链。
2. **账本审计**：能量、钱、人力、时间四项是否收支平衡？谁付钱、谁加班、谁承担废料？
3. **动机审计**：每个制度是否能找到受益者与执行者？没有受益者的制度不会存在。

## 四、常见错误

1. **百科布景**：写大段历史地理，与人物欲望无关。
2. **上层缺失、下层硬凑**：先想好飞船名字再想动力来源，导致处处矛盾。
3. **中世纪默认**：换个星球仍是封建欧洲 + 英语姓名，未问「为何会这样」。
4. **一步到位的完美世界**：没有过渡期、既得利益者与路径依赖。
5. **概念通胀**：每章抛新名词炫技，读者认知预算耗尽。
6. **反向倒逼**：为让某个情节成立，临时发明违反已声明规则的能力。

## 五、实操清单：世界观圣经模板（一页起步）

1. 写一句话核心假设：如果____，那么____。
2. 完成五层推演表，每层至少 3 条因果（上→下）。
3. 写 200 年编年梗概：10 个节点，每个标注类型（技术/制度/灾难/文化）。
4. 写权力地图：谁掌握稀缺资源、谁掌握暴力、谁掌握叙事。
5. 写经济一行式：生产什么稀缺品 → 谁劳动 → 如何分配。
6. 写日常生活 10 件小事（起床、吃饭、付款、丧葬、垃圾）。
7. 标注「本作用到的 20%」，其余归档。
8. 三道审计各跑一遍，记录修补项。

## 六、按需反查：给定场景时的世界观查询表

| 场景 | 需要先确认的层 |
|---|---|
| 一场打斗 | 暴力垄断、武器成本、医疗与法律责任 |
| 一次交易 | 货币、稀缺品、交通与关税 |
| 一场婚礼/葬礼 | 宗教、家族结构、身体技术（能否备份） |
| 一次投票 | 选民资格（AI、克隆人、未成年人是否计入） |

## 本篇要点速查

1. 世界观=因果链，不是名词库；自上而下五层：物理→技术→制度→文化→日常。
2. 上层决定下层，禁止下层为情节方便而倒逼上层。
3. 每个设定必须同时写出：功能、成本、受益者、执行者。
4. 冰山原则：只把会被用到的 20% 暴露给读者，分散注入。
5. 三道审计：因果链是否传导、能量钱人时是否平衡、制度有无受益者。
6. 忌百科布景、概念通胀、中世纪默认。
7. 先有一页圣经，再动第一章。
