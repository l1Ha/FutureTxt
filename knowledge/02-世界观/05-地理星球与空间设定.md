# 地理、星球与空间设定：从物理条件长出文明

## 一、设计顺序：恒星 → 行星 → 后果

环境设定的价值全在**因果传导**。顺序固定：先定物理条件，再推气候与生态，最后才准出现文化。任何一条文化描述，都应能向上追溯到某个物理条件。

## 二、星球设计清单（自上而下勾选）

1. **恒星**：类型与光谱（红矮星耀斑？双日？）、与恒星距离 → 决定光照与温度带。
2. **轨道与自转**：轨道偏心率、自转周期 → 昼夜长短与季节强度；**潮汐锁定** → 永昼/永夜/终昏线定居带。
3. **重力**：与地球比值 → 身材、建筑高度、交通方式、体育、口音（重力低则人高、肺活量不同）。
4. **大气**：成分、密度、含氧量 → 呼吸方式、声音传播（稀薄大气中声音更闷）、防火性、天空颜色。
5. **水与板块**：海洋面积、有无板块运动 → 决定资源分布与地震火山；无板块则碳循环停滞，气候单调。
6. **生态**：光合基础是什么？食物链几级？有无昼夜迁徙的生物节律？
7. **卫星**：有无月球 → 潮汐、历法、夜生活、神话与航海。
8. **资源与异常**：这一颗星球**独有**的一样东西（矿脉、真菌、磁场异常）——它应成为经济与冲突的原点。

## 三、从物理到文化的传导示范

- 潮汐锁定 → 人类只能住在终昏线 → 城市呈环带状、无法「离开」 → 宗教崇拜日出日落的运动方向 → 「向光侧 / 背光侧」成为阶级代称。
- 红矮星耀斑频发 → 地表辐射高 → 文明转入地下 → 艺术以触觉与声学为主 → 地表勘探者是英雄职业。
- 低重力 + 稀薄大气 → 跨城飞行廉价 → 城市垂直铺开、无街道 → 地面成为贫民与拾荒者的层。

**练习法**：任选一个设定，强制写出 3 条向下的文化后果，其中至少 1 条必须进入日常生活。

## 四、空间环境：轨道、深空与尺度

- **轨道站**：重力靠旋转 → 站体形状暴露阶级（外环富、轴心穷）；无法开窗；缓行 7.6 km/s 的窗外即是死亡——太空的戏剧性来自**气闸与压差**。
- **深空航行**：时间膨胀（若接近光速）、通信延迟（地火可达数分钟至数十分钟）→ 指挥链断裂、误判与孤独感；冬眠造成「船员社会周期」与母星不同步。
- **尺度即情节**：星际距离用「延迟」与「物资」表达，不用形容词。旅行时间一旦设定，全书的信件、援军、判决都必须遵守它。
- **居住带**：戴森云、世代飞船、行星改造——每一种都对应一种治理难题（能源分配、船内政治、谁有权改造谁的家园）。

## 五、常见错误

1. **一地球万能**：自转 24 小时、一月四季、人人英语，未做任何条件差异化。
2. **忽视气候带**：纬度、洋流、雨影缺失，地图成了装饰画。
3. **地图无经济**：画了港口却不写谁在这里交易什么。
4. **环境不进日常**：设定里的极端天气从不出现在角色的衣服、作息与俚语里。
5. **尺度失真**：一行军令跨半球抵达，无人谈论时延与燃料。
6. **重力/大气形同虚设**：标了 1.4g 却让角色跳跑自如。
7. **为奇观牺牲因果**：悬空山很美，但无支撑逻辑也无解释需求。

## 六、实操清单

1. 勾完星球清单 8 项，每项标注「与地球相同 / 不同」。
2. 写 3 条「物理 → 气候 → 生产 → 文化」的传导链，至少 4 级。
3. 定义本星球的独有资源，并说明它支撑哪种贸易与冲突。
4. 画草图：标注定居带、资源点、禁入区、交通线。
5. 写一次旅行的时长、能耗与途中补给，记入设定卡。
6. 写 5 个天气/昼夜细节进入正文（衣物、俚语、作息各至少 1 处）。
7. 检查：主角的谋生方式是否依赖此地的地理条件。

## 本篇要点速查

1. 环境设计 = 因果传导：恒星 → 轨道/重力/大气 → 气候生态 → 生产 → 文化。
2. 每颗星球给一个独有资源，让它成为经济与冲突原点。
3. 潮汐锁定、耀斑、低重力都是免费的阶级与宗教素材。
4. 太空戏剧来自压差、气闸与延迟，不来自星云美图。
5. 旅行时间是硬规则：信使、援军、判决都须遵守。
6. 忌一地球万能、地图无经济、环境不进日常。
7. 主角的谋生方式必须长在这片地理上。
