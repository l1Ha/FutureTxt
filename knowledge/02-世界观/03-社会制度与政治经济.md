# 社会制度与政治经济：从技术条件推演权力

## 一、制度由什么决定

制度不是作者的立场声明，而是**资源、技术、组织**三者挤压出的稳定解。同一项技术在不同资源条件下会长出完全不同的制度。推演时先问三件事：

1. **稀缺的是什么**（能源、干净水、轨道位置、算力、基因名额、注意力）？
2. **谁掌握暴力**（国家、企业、帮派、算法、无人机群）？
3. **谁掌握叙事与合法性**（教会、平台、学院、AI 祭司、考古学家）？

## 二、五步推演法

1. **列变量**：核心自由技术 + 本作的稀缺品 + 人口与地理约束。
2. **找受益者**：新技术让谁骤富、让谁失业、让哪种技能贬值？既得利益者会立法、会宣传、会拖延。
3. **定权力来源**（至少两种叠加）：暴力 / 信息不对称 / 合法性 / 稀缺资源配给 / 算法黑箱。
4. **写经济三问**：生产什么稀缺品 → 谁劳动（人、机器、债务奴）→ 如何分配（市场、配给、积分、血统、贡献值）。
5. **做压力测试**：设想 3 场危机（灾年、技术泄密、外部入侵），看制度如何反应——**危机暴露真实规则**，庆典只暴露宣传。

## 三、常见制度写法（速用模板）

| 制度原型 | 权力支点 | 必须回答的问题 |
|---|---|---|
| 轨道巨企国 | 资产与专利、私军 | 主权在哪；劳工如何跨境追责 |
| 算法治理城 | 数据与预测能力 | 谁审计算法；错误率落在谁头上 |
| 后末日教团 | 种子库、药品、旧世界知识 | 知识垄断如何被神学包装 |
| 殖民地议会 | 母星的运输与通信垄断 | 断联后第一年靠什么活 |
| 乌托邦协作体 | 充裕能源 + 高信任 | 外部威胁与懒人/异见者如何处理 |
| 反乌托邦稳定局 | 记忆与生育的管理权 | 底层利益代理与反抗的经济基础 |

**反乌托邦写作铁律**：每个压迫制度都要写出 3 个受益群体与至少 1 个乐意执行它的普通人。

## 四、政治经济写作要点

- **配给优于口号**：写制度靠写购物配额、排队时间、罚单，不靠标语。
- **执行成本**：监控需要预算，告密需要动机，审查需要文员——给制度留出漏损与腐败的缝隙，它才像真的。
- **时间滞后**：技术 5 年到位，法律 20 年才改，观念 3 代才转——错位即剧情。
- **跨境套利**：企业、罪犯、难民总会流向监管洼地，制度边界因此渗漏。
- **货币必有锚**：无论用信用点还是贝壳，写清它最终能换到什么实物。

## 五、常见错误

1. 换皮历史制度：把中世纪封建/20 世纪极权改个名字，未做技术条件修正。
2. 制度 = 政府：忽略家庭、公司、黑市、平台这些真正的日常权力。
3. 全员恶人或全员天使：制度失去中间层与投机者。
4. 反抗组织不缺钱不缺粮，凭理想运转。
5. 忽视性别、种族、世代在制度中的位置差异。
6. 经济万能或经济缺席：要么一切靠钱，要么没人谈钱。

## 六、实操清单

1. 写出本作稀缺品、暴力持有者、叙事持有者各一行。
2. 完成五步推演，产出 1 页制度说明。
3. 写「经济三问」答案，并给货币找一个实物锚。
4. 列出制度的 3 个受益群体 + 1 个普通执行者（写进配角）。
5. 写一场危机压力测试场景（1000 字以内的大纲）。
6. 收集 5 个制度细节：票据、制服、罚则、排队、告示语。
7. 核对时间滞后：技术上线与立法通过差多少年？

## 本篇要点速查

1. 制度 = 稀缺品 × 暴力归属 × 合法性叙事的稳定解。
2. 五步推演：列变量→找受益者→定权力来源→写经济三问→危机压测。
3. 反乌托邦必须有 3 个受益群体和乐意执行的普通人。
4. 靠配额、罚单、排队写制度，不靠标语。
5. 给制度留执行成本与漏损缝隙，腐败即真实感。
6. 技术、法律、观念的速率差是天然剧情。
7. 每种货币都要能换到某样实物；反抗者也得吃饭。
