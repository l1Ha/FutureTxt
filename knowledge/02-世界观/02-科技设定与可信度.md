# 科技设定与可信度：冻结点原则

## 一、可信度从哪里来

可信度不等于「真实」，而等于**约束与代价的可见性**。读者相信的不是科学细节是否正确，而是作者是否承认「没有免费能力」。三条来源：

1. **一致性**：能力在全书范围内的边界始终相同。
2. **代价**：能量、时间、金钱、身体、政治资本——至少付一项。
3. **接口**：技术如何被人使用、误用、维修、盗版，比技术本身更可信。

## 二、冻结点原则（核心方法）

把你的技术栈切成两半，明确**哪些科学作为「已冻结的已知」不动，哪些作为「未知变量」由你自由发明**，这条分界线就是冻结点。

- **点内（冻结）**：角色默认采用我们今天的共识科学。它负责提供读者的信任锚（牛顿力学、经济学常识、人要吃饭睡觉）。
- **点外（自由）**：你设定的那 1–3 项「如果」。它们是故事的发动机，可以违反已知物理，但**必须自带规则与账单**。

操作步骤：

1. 列出本作涉及的全部技术（能源、交通、通信、医疗、武器、计算、生物）。
2. 给每项打标：**冻结 / 自由**。自由项通常不超过 3 项，多了读者无法建立预期。
3. 为每个自由项写三行规则：**能做到什么 / 不能做到什么 / 每次使用付出什么**。
4. 检查自由项是否污染冻结区（如超光速是否破坏因果律、复活术是否使死亡失去重量）。
5. 在大纲里写一张「能力边界卡」，写作时随取随查。

**冻结点可以移动，但必须在文本内明示且一次性完成**，中途移动等于宣布规则无效。

## 三、外推三步法与量级估算

- **外推三步**：①现状（技术今天能做到什么）→ ②趋势（按当前曲线 10/30 年后如何，注意 S 曲线会饱和）→ ③极端（把趋势推到资源或伦理极限会发生什么）。第三步才是故事。
- **费米估算**：关键参数用数量级心算（成本降 100 倍、体积缩 10 倍、能耗 ×10），禁止模糊的「更便宜、更快」。给数字一个量级，读者就能自行想象。

## 四、常见错误

1. **万能技术**：解决了能源就顺便解决人性，一设多用。
2. **只有收益没有账单**：技术免费则社会冲突消失，故事随之死亡。
3. **技术决定论**：仿佛发明即普及，忽略基础设施、标准之争、维修工与既得利益者的拖拽。
4. **冻结点漂移**：前半部是硬科幻，后半部为高潮解禁超能力。
5. **细节真实、系统虚假**：飞船参数精确，却无人谈论谁付燃料钱。
6. **术语堆砌**：用名词密度冒充技术深度。

## 五、实操清单

1. 列技术栈，标出全部「自由项」（≤3）并写下冻结点。
2. 为每个自由项填写「能力边界卡」：能 / 不能 / 代价。
3. 对核心自由项跑一遍外推三步，第三步写成场景。
4. 对关键参数做一次数量级估算，写成具体数字进正文。
5. 列出 3 项「本作绝不允许技术解决的问题」（守住冲突）。
6. 找 1 个真实技术史案例做类比（如抗生素耐药、标准战争），借它的推广阻力。
7. 检查：每项技术在正文中至少出现一次代价或维修场景。

## 本篇要点速查

1. 可信度 = 一致性 + 可见代价 + 使用接口，不等于科学正确。
2. 冻结点：冻结区守共识科学做信任锚，自由区只留 ≤3 项「如果」。
3. 每个自由项必须有三行规则：能、不能、付出什么。
4. 冻结点可移但须一次性公开，中途换规则即毁约。
5. 外推三步：现状→趋势→极端，第三步才是故事。
6. 参数用量级与数字说话，忌「更快更便宜」。
7. 忌万能技术、忌发明即普及、忌只写收益不写账单。
