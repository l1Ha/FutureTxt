# 03 对话与人物声音

本篇解决科幻对话两大顽疾：**术语灌进对话像教科书**、**所有角色听起来是同一人**。核心原则：每句对话都在争夺什么——信息、立场或关系。

## 一、可用设定素材

### 1. 对话的四重功能（一句话至少占两重）

| 功能 | 说明 | 例 |
|---|---|---|
| 推进 | 改变计划、下命令、制造倒计时 | "四十分钟后闸门自动封闭。" |
| 揭示 | 暴露立场、知识水平、隐瞒 | "我父亲就死在那次泄露里。" |
| 冲突 | 目标或价值排序碰撞 | "先救人还是先保样本，你选。" |
| 关系 | 拉近、试探、羞辱、结盟 | 一句玩笑比三段介绍更显亲疏 |

**判定法**：删掉这句对话，如果情节与人物**两者都不掉**，直接删。

### 2. 科幻术语如何自然进入对话

**五种合法入口（按推荐度）**：

1. **教学场景**：需要有**不懂的人**在场——新人、外行、刚苏醒的冻眠者。两个专家互讲常识是最大破绽。
2. **争用场景**：争夺同一术语的**定义权**。例："'这不算殖民，算驻防。''驻防不需要平民身份证。'"——世界观与冲突同时交付。
3. **利害场景**：谁付钱、谁冒险时，人自然抠字眼（检修、账目、剂量）。**人只在有利益时精确。**
4. **三明治法**：术语 → 感官画面 → 情绪反应，术语被夹住就不悬空。
5. **被打断**：解释到一半被爆炸、被驳回、被"说人话"打断——**半截解释更真实**，还能吊住读者。

**术语密度分级（同场保持一致）**：

| 等级 | 每百字术语数 | 适用 |
|---|---|---|
| 稀 | 0–1 | 情感戏、日常、新章节开头 |
| 中 | 1–2 | 常规推进、混合场景 |
| 密 | 3+ | 技术争论、检修倒计时 |

**术语处理三招**：能不用就换**动词**（"把场强降到阈值以下"→"让它安静下来"）；保留术语但**绑一个动作**（一边拧阀门一边说）；**留一个生词**不解释，靠上下文撑——读者容得过一个不懂的词，容不过三个。

### 3. 语言指纹：让每个人听起来不同

| 维度 | 谱系两端 | 例示 |
|---|---|---|
| **术语密度** | 技术黑话 ↔ 全是大白话 | 工程师"法兰" vs 平民"那圈螺丝" |
| **句长与节奏** | 长句嵌套 ↔ 电报短句 | 学者从句连篇 / 老兵"行。走。" |
| **语气与用词** | 敬语、模糊语 ↔ 直给、命令 | "恐怕""大概""是不是可以考虑" |
| **回避方式** | 转话题 ↔ 沉默 ↔ 反问 | 每个人的"不说"都不同 |
| **比喻来源** | 职业与出身决定意象库 | 水手用海、农人用土、程序员用 bug |
| **立场利益** | 受益/受损/无所谓 | 受损者永远先问"谁批的钱" |

**实用技巧**：**口癖限量**（每人一个口头禅+一个禁用词，护士从不说"死"）；**问句习惯**分化（爱反问/只答不问/用问题逃避）；**同一条信息读出三种反应**——分歧即指纹。

**两道测试**：**互换测试**（两人台词对调若毫无违和=指纹失败）、**朗读测试**（能一口气读完通常太"写"，要有停顿、打断与含糊）。

### 4. 信息倾倒（Infodump）的替代方案

| 症状 | 替代法 |
|---|---|
| 两个专家互讲常识 | **立场冲突**：让解释变成辩论，术语为论证服务 |
| 长篇背景交代 | **动作嵌入**：边操作边说，操作本身就是解释 |
| 角色不需要的背景 | **检索/档案**：调资料、读旧新闻，用引文承载 |
| 全知旁白灌输 | **认知落差**：A 知道 B 不知道，B 的追问代替读者提问 |
| 解释后无人反应 | **利害反应**：听完必须有人**立刻改变行动** |

**判断标准**：解释之后，**至少一个人的处境变好或变坏**——否则是作者的私货。

## 二、常见科学错误

| # | 错误写法 | 问题 | 修复 |
|---|---|---|---|
| 1 | 两个老手互讲常识 | 解释动机缺失 | 换成新手在场或术语争用 |
| 2 | 所有角色同一声音 | 互换测试不过关 | 填指纹表 + 互换台词 |
| 3 | 对话只有信息没有立场 | 无冲突 | 每句问"他想得到什么" |
| 4 | 术语堆到每句三个 | 读者弃读 | 密度分级，稀-中-密分场 |
| 5 | 解释后无人反应 | 白解释 | 让有人立刻改变行动 |
| 6 | 对话过短如电报/过长如论文 | 节奏失真 | 保留至少一处跑题与打断 |

## 三、写作时如何解释或规避

**"他想得到什么"三问**（写每句台词前）：他要**信息**、**同意**，还是**关系上的上风**？三无则删。

**潜台词原则**：人物谈**技术与任务**时，实际在谈**信任与权力**。争论"要不要重启反应堆"，底下是"你还认不认我当指挥官"。

**打断、重叠与沉默**：真实对话会打断、接话、答非所问；关键问题后的**空白**比任何回答都有力——一场关键戏至少两次打断、一处沉默。

**让术语承担情绪**：同一术语由不同人说出味道不同——专家说是**权威**，受害者说是**控诉**，孩子说是**陌生化**。

**未来语要克制**：只需三处微调（新词、旧词新义、缩略），不必造语言；过量会毁掉可读性。

## 四、实操清单

1. 为主要角色填**六维指纹表**，各配 1 个口癖 + 1 个禁用词。
2. 每场对话标注**术语密度等级**（稀/中/密），同场一致。
3. 每句台词过**三问**：要信息？要同意？要上风？三无则删。
4. 每段解释后检查：**是否有人的处境因此改变**？没有就重写。
5. 为至少一组关系写**术语争用戏**（同一词的定义权之争）。
6. 关键戏安排**两次打断、一处沉默、一次跑题**，制造真实节奏。
7. 定稿前过**朗读测试**与**互换测试**两道关。

## 本篇要点速查

- 一句对话至少**两重功能**，否则删。
- 术语入对话的合法入口：**新手在场、术语争用、利益抠字眼、三明治、被打断**。
- 两个专家互讲常识是**最大破绽**；人只在**有利益时**抠字眼。
- 术语密度分**稀/中/密**三级，同场保持一致。
- 指纹六维：**术语密度、句长、语气、回避方式、比喻来源、立场**。
- 潜台词：谈技术时实际在谈**信任与权力**。
- 解释之后必须**有人的处境改变**，否则是私货。
