# 01 角色构建方法

本篇解决科幻创作的角色难题：**设定足够宏大时，人如何不被淹没**。核心原则：极端设定是人性的压力测试，不是替代品。

## 一、可用设定素材

### 1. 科幻角色的特殊性

科幻给角色的三件普通题材没有的礼物：

1. **极端情境当手术刀**：隔离、缺氧、时间膨胀、资源归零——把普通人在常规环境下藏得住的东西逼出来。
2. **设定与身份直接冲突**：我是人还是复制体？我效忠地球还是这里出生的孩子？**身份命题即角色命题**。
3. **选择被放大**：在一个按钮能决定十亿人的世界里，**选择即性格**。

**反面教训**：角色沦为"设定说明书朗读者"。判定标准——**如果删掉这个角色的世界设定解说，他/她还剩下什么？** 剩不下，就还不是角色。

### 2. 欲望 / 需求 / 缺陷：角色三脚架

| 层 | 定义 | 问句 | 科幻例示 |
|---|---|---|---|
| **欲望（Want）** | 角色自觉追求的外在目标 | 他嘴上说要什么？ | "找到那艘失联的船" |
| **需求（Need）** | 角色不自知的内在课题 | 他真正缺什么？ | 学会信任他人、放下控制 |
| **缺陷（Flaw）** | 需要的反面，制造真实代价 | 他因何搞砸事情？ | 多疑→在关键时刻拒绝救援 |
| **创伤/幽灵（Ghost）** | 缺陷的来源事件 | 那次到底发生了什么？ | 曾因轻信失去整个小队 |

**三者关系铁律**：欲望与需求**最初方向相反**，结局时二者**要么合一、要么支付惨痛代价**。缺陷必须**至少三次**在情节中造成可观察的损失（不是被口头提到）。

### 3. 主角的认知弧光（Arc）

科幻主角最动人的弧光不是"变强"，而是**对世界的理解被推翻三次**：

1. **初始信念**（开局自洽、有道理、有情感依据）——他坚信世界是 X。
2. **证据冲击**（中点被打脸）——出现无法用 X 解释的事实。
3. **新理解**（付代价后重立）——Y 才是真的，且 Y 比 X **更难受**而不是更舒服。

**科幻专属弧光模板**：

| 模板 | 起点 → 终点 | 例 |
|---|---|---|
| 宇宙观崩塌 | "宇宙为我而设" → "我们在黑暗森林里无关紧要" | 天真探索者 |
| 身份重估 | "我是原生人类" → "复制体也是我" | 义体/克隆角色 |
| 道德重定价 | "为大局可以牺牲少数" → 亲手按下按钮后的动摇 | 指挥官 |

**关键句法**：弧光完成的标志是角色**在旧情境出现时做出不同选择**——同样的问题，第一幕他撒谎，终幕他说真话。

### 4. 群像（Ensemble）构建

**功能-欲望双轨表**（先分功能，再补个人欲望，缺一不可）：

| 功能位 | 叙事作用 | 必须附加的个人欲望 |
|---|---|---|
| 视角/亲历者 | 读者进入世界的入口 | 一个与任务无关的私心 |
| 技术解释者 | 说出设定 | 害怕被技术替代 / 想证明自己那一套 |
| 情感锚点 | 提供温度与 stakes | 想带某人回家 |
| 道德参照 | 提出"我们不该这样" | 自己曾做过脏活 |
| 对立者 | 阻碍主角 | **其主张必须部分正确** |

**群像差异化公式**：**同一处境 × 不同立场 × 不同损失**。差异来自他们**各自会失去什么**，不来自口音与发型。

**群像死亡/离开的价值**：每次减员必须改变**权力结构或规则**（少了能修复引擎的人，剩下的才被迫冒险），否则只是消耗品。

### 5. 让角色"长在设定里"

- **职业来自世界**：小行星矿工会惜物、寡言，把每一克质量都当钱；轨道出生的士兵对"跳下去"有不同理解。
- **世界观立场表**：每人一行——对核心设定**受益 / 受损 / 无所谓**。立场决定态度，态度决定台词。
- **日常细节**：写他们怎么吃饭、怎么问候、怎么打发无聊——**习惯比简历更快立住人**。

## 二、常见错误

| # | 错误 | 问题 | 修复 |
|---|---|---|---|
| 1 | 角色=职业+装备清单 | 没有欲望就没有人 | 补 want/need/flaw 三件套 |
| 2 | 主角开局全知全能 | 无弧光空间 | 让他先错、先信、先输 |
| 3 | 缺陷只在台词里被提到 | 不产生后果 | 让它至少三次造成实际损失 |
| 4 | "被选中的人" | 天赋免除了努力与代价 | 改为"活下来的人"并附幸存者愧疚 |
| 5 | 配角只有一个功能 | 工具人 | 给一个与主线无关的私欲 |
| 6 | 所有人目标一致 | 无冲突 | 让同一目标对不同人意味着不同结果 |
| 7 | 弧光靠别人点醒 | 被动说教 | 让角色自己撞上反证 |
| 8 | 阵营脸谱化 | 阵营内部无分歧 | 每个阵营至少两派 |

## 三、写作时如何解释或规避

**"立场先于台词"**：写对话前先填一行该角色对当前事件的**利益+信念**，台词自然分化。

**认知落差即戏**：同一事实，三人因立场不同读出三个版本——信息不必由旁白灌输，冲突自动产生。

**用选择揭示，不用形容词宣布**：删掉"他很勇敢"，改成"闸门只剩三十秒，他说你们先走"。

**给每个主要角色一个"非任务场景"**：吃饭、赌博、给家里录信。**日常是人物的底片**，极端情境只是显影液。

**档案卡瘦身**：角色卡保留六项即可——欲望、需求、缺陷、创伤、立场、习惯。再多的背景不会自动变成人物。

## 四、实操清单

1. 给每位主要角色填 **want / need / flaw / ghost** 四格，检查 want 与 need 是否方向相反。
2. 写出主角的**初始信念一句话**，再设计一个**只能用反证打破它的事件**。
3. 列**功能-欲望双轨表**，确保每个功能位都有独立私欲。
4. 为核心设定给每个角色标**受益/受损/无所谓**，据此预测台词立场。
5. 让缺陷至少**三次造成具体损失**（错过的救援、翻倍的成本、死掉的配角）。
6. 写完一章做**"删设定测试"**：把解说删掉，角色是否仍做出独特且可预测的反应？

## 本篇要点速查

- 极端设定是**压力测试**，不是角色的替代品。
- 三脚架：**欲望（要什么）、需求（缺什么）、缺陷（为何搞砸）**，欲望与需求开局相反。
- 弧光=**初始信念被证伪 → 更难受的新理解**，终点是做出不同选择。
- 群像差异来自**各自会失去什么**，不来自外形与口音。
- 每个功能位必须附加**与主线无关的私欲**，否则是工具人。
- 立场（受益/受损/无所谓）**先于台词**，利益决定态度。
