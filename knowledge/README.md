# 科幻小说写作知识库（32 篇）

面向中文科幻长篇创作的实操型知识条目。既可作写作参考，也会由 `pipeline/kb.py`
按阶段自动注入流水线提示词（每阶段注入相关模块，上限 1.4~2 万字符）。

每篇结构统一：`##` 分节 + 方法论/表格 + 常见错误 + 实操清单 + 文末「本篇要点速查」。

| 03-核心主题与思想实验 | 奇点、费米悖论、忒修斯之船、模拟假说…如何翻译成处境 |
