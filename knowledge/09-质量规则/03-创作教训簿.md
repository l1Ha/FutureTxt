# 创作教训簿（每完成一篇追加）

> **用途**：经验回流。每完成一部作品，把审校、连续性、文风体检、发行与读者反馈中暴露的问题，
> 压成**一条可执行的规则**追加到本文件；流水线在 concept / world / draft / review / revise / continuity
> 六个阶段自动注入本文件（归属 `09-质量规则` 模块）。
>
> **写法要求**：一条教训 = 现象（哪部作品）→ 根因 → 今后怎么做 → 检查手段（自动化/人工）。
> 禁止写「要写好一点」这类空话；禁止只记现象不记规则。

## 一、结构类

1. **复制章**（《意识纪元》4/5、13/14；《地球2200》4/5：同一场戏换个名字又写一遍）
   → 每章必须推进不同事件，重复桥段一律重写。
   → 检查：跨章 5 字滑窗相似度检测（`lint`），连续性机器预检。
2. **多重收尾**（《喂饭》：写完「（全文完）」又被字数闸门续写出一整套结尾）
   → 检出完结标记后一律停止续写；结尾只保留一套。
   → 检查：完结标记 + 标记后正文长度检测。
3. **续写复述/重启**（《销号》：续写把整篇从头重写了一遍，正文出现两遍）
   → 续写不得复述章尾、不得搬用开篇整句；违反即拒绝拼接。
   → 检查：`continuation_repeats` / `continuation_restarts` 护栏。
4. **转折来自巧合或外力**（《借脸》初稿：巷子里凭空出现一个「修卡的人」帮主角续命三天）
   → 短篇的唯一转折必须来自主角自己的选择；禁止天降救兵、禁止巧合翻盘。
5. **没有反派 ≠ 没有冲突**（《责任官》第一稿：全篇只有主角对着屏幕签字）
   → 必须写出**对立的好 + 稀缺资源 + 时限 + 会开口的代理人**，至少三场活人对峙，每场都有代价。
   → 检查：审校清单新增「活人冲突」一项；写前先填冲突表。
6. **结尾说教**（《借脸》模型修订稿自行补了一句倒计时式总结）
   → 结尾禁止解释性句子、禁止主题升华；模型修订稿要逐句检查结尾。
7. **单一效果失守**（短篇被写成缩小版长篇）
   → 短篇只服务一个印象：一个主角、一个处境、一个转折、一个余味。

## 二、语言类

1. **AI 腔与套话密度**（早年五部长篇 D 级：微微/仿佛/某种/深吸一口气/不是…而是…成灾）
   → 写作时禁用清单入红线；旧作按体检报告定向重写。
   → 检查：`lint`（套话、AI 腔句式、虚词密度、高频四字串）。
2. **填充词**（微微、缓缓地、轻轻地、一种…的…、某种…的…）
   → 确定性瘦身：只在白名单搭配下删除，不做同义替换。
   → 检查：`lint --fix`（原稿存 .bak，前后对比体检分）。
3. **检测误报**（「长时间静止」被当成「时间静止」套话）
   → 套话命中要加前缀排除表；宁少报，不误伤。
4. **长句长段、说明文堆积**（infodump）
   → 单段技术说明 ≤200 字；长句在转折处断开；规格数字要省着用。
   → 检查：句长/段长指标 + 审校红线。
5. **术语过载**（《责任官》初稿 8,646 字，协议条款与传感器规格淹没人物）
   → 规格是调味，人物的账才是主菜：每章科技/制度细节只保留能改变选择的那几处。

## 三、真实题材类

1. **真实新闻必须去标识**（人名、机构、商品、平台、地名全部虚构）
   → 每篇写 `00-选题来源.md`：新闻事实、挑选理由、改变对照表、红线。
2. **先立底稿再写小说**（淮滨、免费经济、传统知识、农膜）
   → 真实结构用真的、制度推演标注虚构；底稿进 `knowledge/11-社会推演`。
3. **政策类新闻要留「半截结局」**（抬头率：不再统计，但摄像头还在）
   → 制度不会因一篇报道彻底改变；忠实比痛快更有力。
4. **数字要与正文对账**（38 亩/20 亩事故：正文改了，设定文档没跟上）
   → 正文是唯一权威；改数字先改正文，再回改设定文档。

## 四、读者性类（来自读者反馈，优先级最高）

1. **「风格太安静没人看」** → 开篇必须有钩子：悖论句、倒计时或一个反常数字；
   前 200 字给出麻烦与代价，先让人物行动，再让读者推断规则。
   （正例：《个案》「三十七个人还活着。系统说，这叫个案。」）
2. **「必须思辨」** → 每篇至少一个**可争论**的核心问题，一句话能写进评论区；
   正文里让正反双方真刀真枪辩一场，**反方必须有道理、有数据、有难处**。
3. **对赌结构** → 给主角一个 deadline 与两难选项，两边都有具体代价；转折的不可撤回性为零。
4. **可转述性** → 每篇至少一处让读者想转述给别人听的设定或细节。
5. **短篇仍只有一个转折**，但转折要「重」：读完之后人物回不到原处。

## 五、流程类

1. **手写优先**：模型初稿过载、跑偏或复述时，按骨架手写收束；模型修订稿常自行添加抒情尾句，须逐句删。
2. **锚点分离**：章节保留 W/C 锚点，出版净稿自动剥离；不要手工删。
3. **项目编号**：`projects/NN_书名`；`init` 自动分配序号，旧名仍可定位。
4. **端点不稳**：先跑离线检查（`lint` / 机器预检），再重试 `review` / `translate`；重试脚本可复用。
5. **经验回流**：每篇完成后把新教训追加到本文件；同一教训只记一条，出现新变体时补进同一条。
