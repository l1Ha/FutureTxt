# 02 章节写作与钩子

## 1. 章节的最小单元：四件套

每章都应完成一次完整微循环——**目标 → 冲突 → 转折 → 余韵**。

| 件套 | 功能 | 写作要求 | 常见病症 |
|---|---|---|---|
| 目标 | 本章角色想得到什么 | 具体、可在一章内表述清楚；最好与全书目标同向 | 目标是"感受一下气氛"这类不可检验的描述 |
| 冲突 | 挡在目标前的力量 | 阻力至少来自两方（外部障碍+内部犹疑） | 只有外部爆炸，人物没有代价 |
| 转折 | 章末状态改变 | 信息、关系、筹码、赌注至少变一项，且不可逆 | 章末回到原点，白读一章 |
| 余韵 | 把读者推向下一章 | 用一个新问题、新画面或新威胁收尾 | 用"他睡着了"式关机收尾 |

**检验法**：合上本章，用一句话说出"这章结束后世界多了什么、少了什么"。说不出＝这章该删或该改。

## 2. 开章钩子的六种类型

1. **动作切入**：从追逐、故障、警报的中段开始，前因后补。适合紧张卷。
2. **异常细节**：一切正常，但有一个不对劲的细节（数字、气味、少了一颗星）。适合悬疑/恐怖向。
3. **结论倒置**：第一段先给结果——"三天后我会杀掉船长"。适合多线结构。
4. **状态宣言**：一句话立起极端处境。"休眠舱第 40 年，氧气只剩 11 天。"
5. **对话交锋**：第一句就是有火药味的对白，省去寒暄。
6. **意象定调**：用一个强画面立氛围（冷开篇），但**必须在 300 字内**接上事件，否则变成风景散文。

**通用规则**：开章 100 字内给出"发生了什么"，500 字内给出"谁想要什么"。

## 3. 章末悬念的七种类型

| 类型 | 手法 | 适用场景 |
|---|---|---|
| 危机悬置 | 危机最高点掐断（不写结果） | 战斗、追逐章 |
| 信息炸弹 | 抛出一个颠覆性事实就收尾 | 反转章、中点前后 |
| 抉择留白 | 人物做出选择的动作，不写选择内容 | 关系、道德困境 |
| 新元素入场 | 结尾出现新人物/新船/新信号 | 卷初、探索章 |
| 倒计时启动 | 明确给出死线 | 生存类情节 |
| 视角切换 | 本视角结束，切到别处的更大威胁 | 多视角长篇 |
| 反向安慰 | 表面危机解除，句尾留一根刺 | 喘息章、假胜利后 |

**注意**：连续 3 章用同一种钩子，读者会脱敏；同一卷内至少轮换 4 类。

## 4. 场景切换与断点管理

- **切场景的三个硬条件**：时间跳变 / 地点跳变 / 主要在场人物跳变——至少满足两个才切。
- **断点选择**：在"读者刚产生疑问"或"答案刚到手、后果未知"处断，不要在对话问答中间硬断。
- **多视角切换**：同一卷内视角数量建议 ≤4；切换按张力递增排序（低张力视角不要接在高潮视角之后，会泄气）。
- **章末与章首配对**：上一章末抛出的钩子，下一章**前 200 字内必须回应**，哪怕只是部分回应——拖延超过一章，读者会感到被耍。
- **过渡处理**：长距离移动用一句话跳过（"两天后，空间站的灯终于出现在舷窗里"），不要描写过程。

## 5. 每章的"信息预算"

- 新名词（人名、地名、技术名）**每章 ≤5 个**，超出则合并或删除。
- 新设定解释**每章 ≤1 处**，且尽量放在冲突的间隙而非开头。
- 若本章必须投放大量设定（如登船、开城），就把钩子放在设定段**之前**和**之后**各一个，形成"三明治"。

## 6. 实操清单

1. 写章前先写一行：「本章 ___ 想要 ___，但 ___ 挡着，章末他会发现 ___。」填不满就不开写。
2. 开章删掉前三段寒暄，直接从事件中段或异常细节切入。
3. 章末写完后，用上面七类钩子各拟一个备选，选张力最大的那个。
4. 全书写完后把所有章末句抽出来单独读一遍，检查是否形成递增的追问链。
5. 统计每章新名词数量，>5 就删。
6. 检查每个钩子是否在下一章 200 字内被回应。
7. 连续三章强度相同的，手动插入一章呼吸章或高压章打散。

## 本篇要点速查

- 每章四件套：目标、冲突、转折、余韵，缺一件就重写。
- 开章 100 字说清"发生了什么"，500 字说清"谁要什么"。
- 章末钩子七类轮换用，同类连续三次必失效。
- 钩子必须在下一章前 200 字内被回应，别吊读者超过一章。
- 场景切换要满足时/地/人三条件中的两个。
- 每章新名词 ≤5、新设定解释 ≤1，设定用"三明治"夹在钩子之间。
- 章末句单独抽读，能连成追问链才算合格。
