# 第4章 数据的裂痕

档案馆的混凝土拱顶在昏暗的潜水灯光下呈现出一种被时间压实的灰白，水流在梁柱间缓缓旋转，带走细小的锈粒。林晏漂浮在服务器室的入口舱门前，左手握着潜鸟‑07机械臂的控制柄，右手则轻触着档案馆自动签名终端的玻璃面板。终端屏幕上，一串淡绿色的字符正以每秒约三十行的速度刷新——那是来自深海数据服务器（DS‑Archive）的实时备份日志。

“备份进度 87%。”机械臂内置的语音模块用低沉的男声报告，声音在水中传播时带来轻微的延迟，像是远处的回声。“剩余估计时间 12 分 34 秒。”

沈莉的声音从耳机里传来，带着她惯用的口头禅：“依照程序。”她的智能环在暗光中闪出一点蓝点，表示她已通过QPN将指令下达到档案馆的入口节点。“请确认恶意硬件已被隔离。若仍有异常信号，请立即切换至安全模式。”

林晏将目光从终端转向机械臂的末端——一根细长的探针正紧贴在服务器机箱侧面的维修接口上。探针尖端嵌入了一块银灰色的金属条，表面刻有微小的焊点，显然不是原厂配件。那正是赵宏团队通过离子切割臂植入的恶意硬件：一个体积仅有拇指大小的固态存储模块，内部预装了能够窃取高精度海平面曲线的后门程序。

“已完成物理隔离。”林晏说，手指在控制柄上轻按，机械臂的夹爪缓缓张开，将那块金属条夹起，然后轻轻放回到服务器机箱底部的防护槽里。槽内衬有导电橡胶，能够在短时间内屏蔽外部电磁干扰。“探针已撤出，接口已恢复原始封装。”

耳机里忽然传来一阵尖锐的电子噪音，像是被某种高频信号撕裂的静电。林晏眉头一皖，随即看到终端屏幕上的备份日志出现了异常：一串未知代码“⟨∅⟩”以每隔约两秒的频率闪现，伴随着备份进度条的轻微抖动。

“⟨∅⟩？”他低声自语，记忆中闪过W6的条文——自动签名终端每日最多记录10 000条签名，超过则进入保护模式。而此刻的异常显然不是签名过载，而是系统在检测到非授权硬件时触发的自我保护机制。

“怎么了？”沈莉的声音带着一丝紧张。“你发现什么了？”

“签名终端出现保护模式标志。”林晏说，“⟨∅⟩ 闪烁，系统似乎在屏蔽某些写入请求。我怀疑那是恶意硬件试图绕过加密广播时产生的冲突。”

“没错。”沈莉答道，“根据W6，终端在检测到异常输入时会自动切换至只读状态，停止接受新签名，同时将已缓存的数据写入本地存档。这也是为什么备份进度卡在87%——服务器正在等待终端释放写入锁。”

林晏 nods，尽管水下看不见他的表情，但他能感觉到潜水服内部的微微震动——那是他心跳加速的生理反应。他快速在终端侧面的维修面板上打开一个小型接口，插入潜鸟‑07携带的诊断探针。探针的光纤在水中发出微弱的蓝光，随即在终端的副屏上弹出一个诊断窗口：

```
[ALERT] Unauthorized hardware detected on SIG‑PORT.
[PROTECTION] Write lock engaged. Daily signature limit approached.
[RECOVERY] Manual override required to clear lock.
```

他将诊断数据通过QPN加密广播发送给沈莉和UN‑OAL深海档案库的主管迪亚洛。几秒后，迪亚洛的声音在耳机里回荡，带着他一贯的口头禅：“数据永恒。”

“迪亚洛，确认终端已进入保护模式。”林晏说，“需要人工复位才能继续备份。根据W6，复位必须由具备静脉纹授权的操作员现场执行，否则系统会保持锁定状态。”

“没错。”迪亚洛回复，“我已调取你父母的静脉纹模板。你母亲林梅的静脉纹哈希在档案馆的授权库中仍然有效。请使用你的左手静脉纹进行验证——系统将接受直系亲属的备用授权。”

林晏 hésitation片刻。他想起母亲在档案馆签名终端上留下的最后一笔签名——那是在2123年12月31日，距离极端冰盖崩解事件不到几个小时。父亲林浩曾参余热热电系统的安装，母亲则在签名板上留下了她的名字与日期。此刻，他不仅要面对数据的安全，还要面对可能揭开父母命运的钥匙。

他将左手慢慢伸向终端旁边的静脉纹扫描窗口。窗口内部的红外线轻轻扫过皮肤，随后屏幕上出现一串绿色的确认标识：“静脉纹匹配 – 授权级别：直系亲属。”

“授权成功。”林晏说，“现在执行复位。”

他按下终端侧面的复位按钮——一个被防水硅胶包裹的凹陷金属圆钮。按钮下沉的瞬间，终端发出低沉的嗡鸣声，屏幕上的“⟨∅⟩”闪烁逐渐减弱，直至彻底消失。备份进度条随即跳动，从87%猛然升至92%，然后平稳地向100%推移。

“备份完成。”沈莉的声音带着一丝如释重负的语调，“数据已同步至UN‑OAL深海档案库，完整性校验通过。请确认服务器状态。”

林晏将目光投向服务器机箱前面的状态指示灯。三盏灯依次从红色变为琥珀色，最后定格在淡绿——表示服务器已进入低功耗待机模式，所有数据已安全写入本地存档并通过QPN加密广播发送至远程备份节点。

“好了，”他说，“服务器已安全存档，签名终端恢复正常。按照W4，TEG‑Base的余热热电输出目前读取为1.19 kW，仍在安全范围内。”

耳机里突然传来赵宏的咆哮，声音像是被水压缩后又爆裂开来：“你们以为能藏住数据？我会让这座坟墓变成我的金库！”

林晏的耳机里同时传来金属撞击的尖锐声——那是赵宏离子切割臂的等离子体尖端正在撞击档案馆入口的混凝土梁，溅出星星点点的蓝白色火花。水流在高温下瞬间汽化，形成一层薄薄的水雾，像是海底的呼吸。

“好了，”沈莉说，“我们已经完成了备份。请立刻撤离，档案馆将在接下来的几分钟内进入自保护状态——基座余热将在结构应力超过阈值时触发热失效，导致服务器掉电。这也是W4所允许的短时能量缓冲。”

林晏看向远处的水面，UN‑OAL巡逻艇“潮澜‑03”的灯光在波浪中若隐若现，像是远方的灯塔。他深吸一口气，潜水服内部的空气在肺叶里轻微膨胀——那是他准备离开前最后的平静。

“我会留下来确保撤离完毕。”他说，“你先返回艇上，通知迪亚洛备份完成，并准备好应对可能的结构位移。”

沈莉没有多言，只在智能环上轻点一下，表示指令已发送。她的身影在水流中渐渐变淡，直到只剩下一串淡蓝的光点——那是她智能环在远距离传输时留下的残光。

林晏转回档案馆入口，机械臂的夹爪轻轻放回到服务器机箱旁的维修架上。他看着终端屏幕上最后一行日志：“Backup completed at 2200‑04‑14 02:17:03 UTC. All data replicated to UN‑OAL Deep Archive.” 

随后，他缓缓后退，潜鸟‑07的推进器发出低沉的嗡鸣，将他推向档案馆的拱顶。水流在他身侧汇聚，带走他身上的细小气泡。就在他即将离开服务器室的那一刻，终端屏幕再次闪现——这一次不是“⟨∅⟩”，而是一行极小的字符，几乎被水流的折射掩盖：

```
2123-12-31 L.H.
```

那是父亲林浩的名字与日期，藏在母亲签名旁边的角落里，像是一种无声的承诺。林晏的手指悬停在玻璃面板上，却没有按下任何键。他知道，有些真相不需要被签名确认，它们已经沉入了水底的记忆里，随潮汐一起起伏。

他推开潜鸟‑07，向着水面游去。耳机里，赵宏的怒吼渐渐被远去的潮声掩盖，只剩下水流低鸣与金属沉闷的碰撞——那是档案馆在余热热电的最后一点能量支撑下，开始缓缓下沉的声音。

就在林晏即将突破海面的瞬间，耳机里传来沈莉的声音，轻柔而坚定：

“数据已安全存入深海档案库，你……你还好吗？”

林晏没有回答。他只是让潜水服的面罩在海面上划出一道弧线，阳光在水滴上折射出七彩的光环——那是他在这片沉没旧城里，终于看到的一丝希望。
