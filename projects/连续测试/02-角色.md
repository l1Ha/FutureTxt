# 角色体系
## 关系网（谁与谁：依赖/对立/隐瞒）
- **林晓** ↔ **陈漾**：同舱维修学徒，互为技术伙伴与情感依赖；晓依赖漾的磁带复制技术，漾依赖晓的通风管路径知识。  
- **林晓** ↔ **梅里**（记忆管理部低级档案员）：隐瞒——梅里在例行销毁旧磁带时偷录了地球片段并悄悄交给晓，但不敢公开身份。  
- **林晓** ↔ **舰政委员会代表韩澈**：对立——韩澈负责执行“思想净化”及防恐条例，视晓的行为为一级违规。  
- **陈漾** ↔ **李锋**（危险作业区老工）：依赖——漾常向李锋换取废弃磁带与废金属，李锋则利用漾的技术获取额外配给。  
- **梅里** ↔ **记忆管理部主管赵岚**：对立——赵岚推动全舰净化，梅里私藏旧档案构成内部威胁。  
- **韩澈** ↔ **赵岚**：依赖——两人共同制定“防恐”政策，韩澈提供执行力，赵岚提供信息依据。  

## 角色：林晓
- 身份与处境 / 外貌标志 / 欲望 / 需求 / 缺陷 / 秘密 / 人物弧光（起点→终点） / 语言指纹（口头禅、术语密度、句长） / 与主线的关系  
- **身份**：底层生活舱维修学徒，负责通风管与旧式音频设备检修。常戴磁吸鞋，左耳后有旧式焊点疤痕。  
- **外貌标志**：右手食指常沾有金属磨粉，因常在狭窄管内作业。  
- **欲望**：听见并验证“地球”到底是什么样的地方，以此回答“我从何而来？”  
- **需求**：学会在信息与安全之间取得平衡，不必以牺牲伙伴为代价才能获得真相。  
- **缺陷**：过度依赖技术手段获取真相，常忽视人际关系的脆弱，导致关键时刻选择孤行而忽略伙伴警告。  
- **秘密**：偷藏了一段地球影像磁带副本，并在私下向三位同舱孩子播放。  
- **人物弧光**：起点——相信只要拿到原始录音就能改变一切；终点——接受真相的传播需要集体行动，愿为伙伴承担后果而自我牺牲。  
- **语言指纹**：口头禅“行吧”，术语密度中（1–2/百字），句长偏短，常用断句与省略号。  
- **与主线的关系**：主角，其行动直接触发底层觉醒与上层净化危机，推动核心冲突。  

## 角色：陈漾
- **身份**：底层生活舱同龄维修学徒，擅长磁带复制与低功率广播装置改装。常穿带有补丁的工装裤，右手腕戴自制磁带计数器。  
- **外貌标志**：左眉上有一道细小的烫伤疤，是曾在磁头退磁时的意外。  
- **欲望**：掌握足够的技术资本，换取更高的磁带配额，以免被调往危险作业区。  
- **需求**：认识到技术不是孤立的力量，必须与人际信任结合才能真正改变处境。  
- **缺陷**：过度实用主义，倾向用交换与谈判掩盖真情实感，导致在危机时刻难以得到真正的伙伴支持。  
- **秘密**：曾私下为记忆管理部低级员工复制过“思想净化”广播，换取额外食藻，但始终未被发现。  
- **人物弧光**：起点——认为只要拥有足够的磁带就能保证自身安全；终点——愿意将自己的技术用于公开传播，即便意味着失去个人利益。  
- **语言指纹**：口头禅“等等”，术语密度稀（0–1/百字），句长较长，喜欢在解释时加入比喻（“就像给老管道换心脏”）。  
- **与主线的关系**：晓的主要伙伴，提供磁带复制与广播技术，是信息传播的关键节点。  

## 角色：梅里
- **身份**：记忆管理部低级档案员，负责旧磁带的登记与销毁。常佩戴银色档案员徽章，左胸有微磨损的磁带槽痕迹。  
- **外貌标志**：说话时习惯用左手指弹磁带盒边缘，产生轻微嗒嗒声。  
- **欲望**：保住自己的档案员职位，避免被降级至危险作业区。  
- **需求**：在体制内找到一种方式让被遗忘的记忆不被彻底抹去，哪怕只能以微小方式传承。  
- **缺陷**：害怕直接对抗体制，选择以偷偷复制与私下传递的方式行动，导致信息零散且易被追踪。  
- **秘密**：在例行销毁流程中偷录了完整的地球影像片段，并通过维修学徒网络传给林晓。  
- **人物弧光**：起点——认为只要不被发现就能保护记忆；终点——接受自己可能成为牺牲品，决定在即将被审讯前将副本交给更多人。  
- **语言指纹**：口头禅“据我所知”，术语密度密（3+/百字，常出现“档案屏蔽”“磁退化”等专业词），句长中等，语气偏正式。  
- **与主线的关系**：信息的最初泄露源，为晓提供了触发叛乱的关键素材。  

## 角色：韩澈（舰政委员会代表）
- **身份**：舰政委员会执行委员，负责底层舱段的秩序与“防恐”条例执行。常穿金色委员会制服，左肩有舰徽金属徽章。  
- **外貌标志**：走路时左脚略微外八字，是长期在重力旋转段与轴心区域切换导致的步态。  
- **欲望**：维持舰体秩序，确保航程不被任何信息波动偏离既定航向。  
- **需求**：认识到单纯压制信息只会制造更大的危机，真正的稳定需要透明与参与。  
- **缺陷**：倾向将所有未知视为威胁，过度依赖强制手段，导致在危机升级时失去谈判空间。  
- **秘密**：私下曾向记忆管理部申请过对地球影像的有限解密研究，但被驳回后选择掩埋此记录。  
- **人物弧光**：起点——相信严格的信息管制是航行成功的唯一途径；终点——在看到底层孩子们的自发组织后，开始质疑现行政策的有效性。  
- **语言指纹**：口头禅“必须”，术语密度中（1–2/百字），句长偏长，常带有条件从句（“如果……，则……”）。  
- **与主线的关系**：主要对立力量，代表上层对信息垄断与秩序的维护。

## 角色一致性要点（编号 C1、C2… 至少8条，供审校引用）
C1. 林晓的左耳焊点疤痕在所有出场镜像中必须保持一致，不可随意出现或消失。  
C2. 陈漾右腕磁带计数器的显示数字应随剧情递增或递减，且不得在同一场景出现两次不同读数。  
C3. 梅里左手指弹磁带盒的嗒嗒声只在她紧张或思考时出现，放松状态下不应有此声音。  
C4. 韩澈的左脚外八字步态在重力段与轴心切换时应更明显，在旋转段内行走时应较为正常。  
C5. 赵岚的银色档案员徽章必须始终佩戴在左胸，且不得出现在其他角色身上。  
C6. 李锋的黑色工作服袖口应有明显的油污痕迹，且该痕迹在每次维修后应有所变化但不得完全消失。  
C7. 周宁负责的水培灯光箱在章节中光照强度应与剧情描述的藻类产氧峰值（“藻呼”）保持对应关系。  
C8. 吴朵负责磁头清洁时使用的工具应为软毛刷，且不得在同一情节中出现金属工具的描述。  
C9. 郑博在检查激光网络时必须提及“振动敏感”和“丢包”概念，不可在未解释的情况下直接说“网络正常”。  
C10. 孙藻每次调节藻类光照时都应提到“色温4000K”和“照度约150lx”这一具体参数，确保设定落地。
