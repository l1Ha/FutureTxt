# 第6章 深入零点

深夜的人工岛被一层薄雾笼罩，海风从东侧的风电场掠过，带来盐腥与金属的混合气味。零点封存中心的十二座 ZeroPod 舱排列在混凝土平台上，每个舱体外壳覆着哑光的陶瓷隔热层，表面嵌有微型光伏阵列，为舱内低温维护提供补充能源。红外探测器的微光在雾中划出短暂的虚线，像是海底的信标。

林舒站在舱外的维修通道口，身着深蓝色的工程服，左肩别着司法部标发的微型 NFC 工牌——今天她的编辑次数尚未超过上限，工牌没有红光警示（C6）。她的左耳后隐藏的神经能量采集环在微风中泛出淡蓝光，正是她唯一能感知到与低温场相连的信号（C1）。采集环的光强随舱体的能量波动而微微跳动，仿佛在提醒她：这里的温度正在以约 1.5 kW 的持续功率被从四周抽走（C10）。

通道入口处的身份核验终端闪烁着蓝色的条纹。林舒将伪造的维修工程师凭证——一张带有磁悬轨道维修编号的智能卡——刷过读取区。终端低声提示：“身份确认，权限等级：维护-B，允许进入舱外维护区。” 她轻吸一口气，脑中闪过方正那副偏光神经能量过滤眼镜在走廊尽头的微光（C5），以及顾明在办公室里编辑备案芯片项链的轻微振动（C3）。她知道，若被发现私自靠近 ZeroPod，将触发 W4：私人操作属于犯罪，罚没全部记忆资产并处五年监禁。

舱门的气压平衡阀发出轻微的嘶嘶声，舱体外壳的温度传感器显示 -148℃。老李的口头禅在她耳边回响：“-150℃别开玩笑。”（C8）她将手套贴在舱体表面，金属的冷意透过防护层传来，像是深海的寒流在她掌心结冰。

维护通道内部是一条狭窄的走廊，两侧排列着能量补给管线和冷却液回收槽。每六小时，系统会自动启动一次能量补给——这是 C8 的硬性规定：低温维护需每六小时进行一次能量补给描写。此时，管线末端的微型聚变堆正在以脉冲方式输送约 0.3 kJ 的神经能量等价物（相当于 0.083 Wh），以抵消舱体持续散失的 1.5 kW。林舒在管线旁的维修日志终端前停下，调出最近的日志文件。

日志以纯文本形式记录，未加密——这是维护人员为了快速查阅而故意保留的便利。她滚动查看，直至看到一条异常条目：

```
[2090-03-01 02:14:07] 受试者 LS‑34，封存起始 2090‑03‑01，预期解封 2100‑03‑01，舱号 ZP‑0427，备注：TraumaWipe 双相抑制。
```

林舒的心跳几乎停顿。LS‑34——那是她在官方档案中仅见过的编号，对应她的出生年月日。预期解封日期正是今天，2100‑03‑01。她左耳后的采集环蓝光在此刻突然亮起，像是被某种无形的频率唤醒（C1）。她记得自己在十年前被官方记录为“创伤抹除”（TraumaWipe），而现在却看到同样的编号被标记为“计划·清零”封存舱的起始点。

她的脑中迅速过遍硬性设定：W3 规定创伤抹除只能封存约十年，解封后需突触重建疗法；而 W4 明确禁止私人操作 ZeroPod。眼前的日志却表明，她曾被国家批准的设施用 ZeroPod 封存整整十年，期间记忆被物理隔离在突触蛋白聚集体中，若解封后不进行突触重建疗法，将导致永久性情感失调（W3）。

她的手指在日志终端上悬停，想要复制这条记录作为证据。然而，终端的侧边栏弹出一个警告框：“未授权访问 Level‑3 记忆，已记录并通报方正办公室。” 她的神经能量采集环蓝光闪烁加快，仿佛在警示她已触及某条红线。她深吸一口气，决定不在此处停留——舱内的温度监测系统正在异常。

就在她准备转身离开时，舱体外壳的温度显示器突然跳动，数字从 -148℃ 飙升至 -6℃，随后定格在 6℃。红色警报灯在舱门上方闪烁，伴随着刺耳的蜂鸣声：“舱内温度异常升至 6℃，请立即撤离。”

林舒的左耳后采集环蓝光在这一刻几乎要熄灭，她能感觉到能量采集环的微弱电流在急剧下降——这正是能量不足导致的自动降频现象（W9）。她迅速按下舱门的紧急解锁按钮，舱门在压差的作用下缓缓打开，一股带着金属味的冷气涌出，像是被打开的冰箱。

她不顾通道内部的能量补给管线仍在低吼，踉跄着跑向维护通道的出口。身后的舱门在她身后重新合合，警报声逐渐被海风掩盖。她跑出舱区，踏上人工岛的钢格板平台，脚下的金属发出低沉的嗡鸣——那是能量补给系统在试图重新平衡舱内温度时产生的磁振动。

夜风吹乱她的长发，左耳后的采集环蓝光终于稳定下来，微弱却持续。她站在平台边缘，望向远处的海面，海面上风电机组的叶片缓缓转动，将风能转化为电能，再通过海底电缆输送到封存中心的聚变堆。她知道，自己刚才看到的日志只是冰山一角，却已经足以让她在接下来的调查中站住脚步。

她低声自语，声音被风带走：“数据不撒谎。”

这句话像是她的锚点，也像是她在制度与个人真相之间唯一能依靠的线索。她将左手放在胸前，感受到心跳与远处低温舱的金属嗡鸣同步——就像一场即将到来的对决的序曲。

就在她准备返回核心区之前，她注意到维护通道入口旁的工具箱上贴着一张褪色的标签：“-150℃别开玩笑——老李”。她将这张标签撕下，塞进工服口袋，作为以后赢得维修员信任的筹码。

她转身迈步，脚步在钢格板上发出均匀的回声，采集环的蓝光在夜色中划出一条短暂的轨迹，像是在黑暗中留下的唯一证明——她曾经深入零点，看见了不该存在的记忆。
