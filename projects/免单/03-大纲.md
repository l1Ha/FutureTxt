# 全书大纲
## 故事线概览（200字内）
2126年九河街，老范面馆三十一年老汤不在「中央厨房认证目录」里。隔壁零元面馆用善分换走街区流量，老范月产善分为零、房租涨两成、流量位归零。监管以「精准名录」压缩普惠，平台回收节点重新招标：签约即接手免费额度、换装标准底料、授权全量数据、招牌可留。女儿在对面店戴着骨传导贴片劝签，平台经理摆好未拆封中性笔与复写纸，监管员拍下《实施细则》第3条，代排员在队尾刷脸，老熟客老王掏出皱巴巴二十元说「我自己买得起」。老范在账本最后一页、女儿转账备注「别问」的压痕上，算清每一笔死账。中午蒸汽里他尝到汤咸度漂移0.5克，傍晚合同最后一页笔尖划破复写纸，露出「老范老汤（非标）— 已剔除」。他签了，拧紧笔盖，关火盖盖，门外队伍脚步声还在远处。

## 第1章 老汤不在目录里
- **场景（地点与时间）**：  
  2126年11月，河西区九河街320米处「老范面馆」后厨与前堂。跨度清晨04:00起火熬汤至深夜22:00签约收尾。核心空间：直径1.2米不锈钢大汤桶（桶沿1995年焊痕）、红皮账本（铅笔流水/红笔圈房租/蓝笔标偏好）、玻璃隔断外零元面馆排队黄胶带盘至街心花园、平台区域运营中心临街会议室（共用监管所派驻办事处）。
- **本章目标**：  
  老范在「签掉三十年老汤换门口队」与「守住非标老汤等冬天倒闭」的二元困境中，独自完成签名这一不可逆动作，并独自承担关火盖盖的物理后果。
- **核心冲突**：  
  1. **账本与生理的零和**：房租涨20%、燃气涨30%、人工涨40%、面价十年不动，月产善分0 → 现金流撑不过冬天（外部压力）。  
  2. **女儿范小满**：右耳骨传导贴片亮着「善流伙伴」工装，用「日均出餐320单、投诉率0.3%」劝签，实则把老范12个熟客画像偷录进零元店名录（C5/C6，血缘依赖/理念对立/隐瞒）。  
  3. **陈经理**：中性笔笔帽朝左笔尖朝右平行摆放（C7），按SOP第4步回应异议「系统不支持该字段」，合同夹层藏着「老李烧饼」备用转让函（C8，资源垄断/隐瞒下家已定）。  
  4. **赵科长（监管）**：拍下《精准名录实施细则》第3条「三重确认」，不接烟，只认「覆盖率/投诉率/可审计」三指标（W6，把普惠压缩为定向）。  
  5. **老王/阿姨/代排员小马**：老王掏20元现金「不用占名额」，阿姨画像分680被卡队外，小马揽活「刷个脸5元」（W3，免费异化为资格审核）。  
  6. **老李（烧饼店）**：喘气跑进来「不签下家就是螺蛳粉，这条街不签的都得死」（W5，节点竞标者镜像）。
- **转折/结果**：  
  **唯一转折来自老范自己**：在陈经理「明早十点新底料送到」的标准收尾语落下前，老范左手食指指腹浅沟（C1）按住复写纸，笔尖划破第142行「老范老汤（非标）— 已剔除」小字（C9），签名。无犹豫、无独白、无第三条路。签名即关火令。
- **信息与世界观揭示（滴灌式，绑利害）**：  
  - 善分指数：隔壁屏幕实时计数4.2万/月 → 折算房租减免1.8万/流量位3.5万/税抵0.9万（W1，老范账本空白栏对比）。  
  - 认证目录v3.7：牛骨高汤浓缩包CBT-089、红烧酱油包CBT-211……第142行尾注「非标·未收录·不可接入」（W2，老范翻页手指摩挲油烟边缘）。  
  - 精准名录三重核验：街道民政+平台画像+商户终端，延迟3.2秒，画像分<700拦截（W3，代排员手机实操演示）。  
  - FDA-v9第7款：「永久、不可撤销、全球范围用于模型训练、衍生产品开发」（W4，老范指尖触到账本1995年铅笔字「开业第一天 收18元」）。  
  - 节点拍卖引擎：物理门牌绑定额度，招牌可留、底料数据定价权归平台（W5，老李转让函骑缝章实锤）。  
  - 老汤物理实在性：菌群动态、咸度漂移0.5克、油花少两圈、沉淀物厚指甲盖（W7，老范固定动作：舀碗→吹两口→吸一口→咽下→放勺，不加形容词）。
- **伏笔/回收**：  
  - 伏笔：开篇04:00老范左手食指指腹蹭勺柄磨出的浅沟（C1）→ 回收：签名时同一指腹按住复写纸、拧紧笔盖。  
  - 伏笔：账本最后一页红笔圈的不是房租，是女儿转账备注「爸，这是我兼职的钱，别问」压在开业发票上 → 回收：签名前老范指尖摩挲该处压痕，未动用那笔钱。  
  - 伏笔：范小满右耳骨传导贴片细线全程在场（C5）→ 回收：老范签名瞬间，对面店骨传导里播报「节点激活成功」，她第一次没回「收到」。  
  - 伏笔：陈经理中性笔未拆封、平行摆放（C7）→ 回收：签名后他盖帽入包，手机震动「九河街节点激活率100%」删了不看。  
  - 伏笔：老王掏20元「我自己买得起」→ 回收：结尾老范关火盖盖，门外队伍脚步声还在远处——队里队外，老王在队外。
- **章末钩子**：  
  勺子搁在灶台缺口，汤面油花在余温里慢散。玻璃门外，街心花园那头传来整齐的脚步声——黄胶带还没拐到这边，蒸汽先飘过来，裹着中央厨房香精勾兑的「骨汤味」，盖住了三十年老汤最后一口咸度。
