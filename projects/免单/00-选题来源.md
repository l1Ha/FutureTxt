# 选题来源与去标识记录（《免单》）

> 采集日期：2026-11-10。选材自 2026-11-09 澎湃新闻转央广网报道《"零元面馆"排长队、有周边商户生意下降，当地市监局：多部门正牵头处理》。
> 本文件只作创作溯源，不进入正文、不进入任何导出净稿。

## 一、新闻事实（未改动）

- 南京两家"零元面馆"：不按年龄、经济状况限定对象，市民前来吃面不用付钱；
- 中午 11:30 门前排长队，上百人，隔离栏围出通道；有外卖员、快递员，更多是周边普通市民与中老年食客；
- 周边商户：一家淮扬面馆估算营业额下降两至三成；一家锅盖面店称中午客流"少了一半"；也有螺蛳粉店称影响不明显；
- 监管：区市监局称慈善行为本身不违法，不能因此要求其停止；已多次到店询问、约谈，暂未发现盈利或炒作；是否不正当竞争"尚无定论"；
- 律师分歧：一派认为无偿供餐不被禁止、客源分流不等于不正当竞争；另一派认为不能仅因免费就排除商业目的，应看是否借免费引流、排挤对手（价格法低价倾销视角）；
- 专家建议：慈善要算"经济账"，明确服务对象、控制成本、与社会机构合作，把资源用在真正需要的人身上，并评估对周边商户的影响。

## 二、挑选理由

1. **冲突是现成的、人对人的**：免费的一方、被分流的一方、监管、律师、说话的人都在这条街上；
2. **代价具体**：一碗面、一天房租、一条队，全部可量化；
3. **映射当下结构**：平台补贴战、公益营销、低价倾销边界、"精准帮扶"的资格审核、流量与善意的合谋；
4. **与既有作品不重复**：《喂饭》写照护计价，《借脸》写形象授权，《责任官》写责任下沉，这篇写**善意经济的外部性**。

## 三、改变真实信息（去标识清单）

| 新闻中的真实信息 | 小说中的虚构替换 |
|---|---|
| 南京、江宁区 | 虚构城市「临河市」老城南片区 |
| "零元面馆"及运营方 | 虚构店名「开饭」、虚构平台「善流」 |
| 淮扬面馆、锅盖面店、螺蛳粉店 | 虚构的「老范面馆」与邻居「秦记」「永和」等 |
| 市监局、区委宣传部 | 虚构的「片区市场监管所」与「街道协调办」 |
| 律师、专家意见 | 不出现；改为监管员与平台经理的现场口径 |
| 报道中的具体数字（两三成、一半） | 量级相近但已改动（老范掉四成，邻居掉两三成） |
| 2026 年 | 推到 2126 年（未来为镜） |

**红线**：正文不得出现任何真实店名、平台名、地名、机构名与新闻原句；人物、合同与制度全部虚构。

## 四、推演目标（供 concept / world 阶段使用）

- 未来设定：「善流」计价体系（善分可换流量位、房租减免）、「配给名录」（免费只对名录内人群）、「善意节点竞标」（一条街一个名额）、「中央厨房认证」（非标食材不可供餐）；
- 映射的当下结构：平台补贴与价格战、公益营销、低价倾销与不正当竞争的边界、精准帮扶的资格审核、手艺与供应链标准化的冲突；
- 情节显形：老范必须签一份「善流联盟」盟约，才能保住招牌；代价是倒掉三十一年的老汤。

## 五、单一效果与红线

- 单一效果：**免费不是价格，是位置**——它把人分成队里和队外。
- 唯一转折：老范在盟约上签字（自己的选择）。
- 结尾不解释：落在 0.00 的价格屏与一声"面好了"上。
- 冲突要求（沿用《责任官》的教训）：至少四场**活人与活人**的对峙——代排员、女儿、监管员、平台经理；每场都要有账可算。
