# 全书大纲
## 故事线概览（200字内）
惊蛰过后，七十一岁的老葛在鲁南葛庄垄沟里捡拾上季残留的地膜碎片，装入第十九个玻璃瓶。儿子葛胜利按斤买「工程膜」省钱，村口老赵后屋暗售同批次薄膜，孙子小军在临沂打包厂给这薄膜贴标签。县农技站技术员周建新取走十九瓶样品入制式袋、贴条码、上传平台，老葛窗台空了。三日后大风天，老葛捡到一片印着「程」字半偏旁的残膜，未装瓶，亦未弃沟，走至村头老槐树下锈穿底的废旧农药瓶回收箱前，将残膜塞进最深处的锈洞，拍手回家。土地把账记在碎片里，人把账记在动作里，风吹过锈洞，白膜抖动一下。

## 第1章 拾膜
- 场景（地点与时间）：鲁南葛庄，惊蛰后第三个清晨（3月8日前后），麦田垄沟与老葛住宅窗台、赵氏农资店、县农技站采样车、村头老槐树下回收箱；时间跨度约十天（惊蛰捡膜 → 技术员取样 → 三日后大风塞膜）。
- 本章目标：老葛完成第十九瓶「归档」，应对技术员带走瓶子的「清仓」，在儿子算账、孙子逃离、老赵避险、技术员完指标的多方挤压下，独自做出最后一次「归档」动作——将带字残膜塞入废弃回收箱锈洞。
- 核心冲突：
  1. **身体与标准**：老葛脊椎固定45度弧度、指甲缝嵌黑泥白丝、肺叶沉积微塑料咳嗽，对抗0.01mm国标在风里碎成飞絮的物理现实。
  2. **规避体系与生存账本**：葛胜利算「工程膜」省下化肥钱交药费，老赵算熟人情面与承诺书挡箭牌，小军算打包厂扣款与奶粉钱，周建新算20个点位指标与编制希望——四本账互不相让，老葛的十九瓶实物证据成了唯一不属于任何人账本的「异物」。
  3. **记录权的转移与抹平**：技术员带走瓶子倒入自封袋、贴条码、扫码上传，十九年物理归档瞬间转化为平台数据，老葛从「记账人」被清空为「采样对象」，窗台空了，账没了。
- 转折/结果：技术员走后第三天，大风卷起比往年更早更密的白色碎片。老葛捡到一片印有「工程膜」字样、仅存「程」字半偏旁的残膜。他未装瓶（瓶子已无），未弃沟（沟里全是），亦未予儿子或技术员。他走至村头老槐树下废旧农药瓶回收箱前——箱体锈穿底、风吹空空如也，锈洞直径约三厘米。他将残膜攥在手心，塞进锈洞最深处，拍了拍手上的土，不回头往家走。转折来自老葛主动选择的「归档」对象与方式：从玻璃瓶/窗台/自设台账，转向锈洞/废箱/无人可查的物理缝隙。
- 信息与世界观揭示（滴灌式，不设讲座）：
  - GB/T 13735-2017 国标0.01mm厚度仅存在于老赵前屋包装袋与技术员记录单上；后屋货、胜利地里膜、小军厂里膜均为0.006-0.008mm「工程膜」。
  - 按重量报价（元/斤）导致越薄越划算：胜利算账「一亩省八块、三十亩二百四、抵两袋尿素」。
  - 老赵墙上「不销售不合格地膜承诺书」签名按手印齐全，柜台下锁两垛同批次货，熟客喊「赵叔」进后屋，微信备注「农资」/「杂款」双码分账。
  - 回收补贴形同虚设：去年「集中回收日」编织袋底垫石块、顶铺整卷拍照，技术员翻出袋子老葛指着说「这账记在土里呢」。
  - 小军临沂厂日薪180元贴「工程膜」标签，风衣领口沾白色静电纤维，回村骂爷「傻」转身买298元奶粉。
  - 老葛养老金40%买右美沙芬复方甘草片，拒绝去县医院拍CT（300元贵、像进棺材），不识字只认手感风向瓶子重量。
- 伏笔/回收：
  - 伏笔：开篇老葛指甲缝挑白丝动作 → 结尾塞膜进锈洞前攥在手心的触感呼应。
  - 伏笔：第一瓶（1996年）混入「长寿牌」完整边角、老伴因烧膜烟哮喘离世的秘密 → 中段技术员倒瓶时老葛盯着那片商标碎片入袋，未言、未阻、只觉「又少了一年账」。
  - 伏笔：胜利计算器「0」键卡顿需用指甲用力按、伴随「嘶」声吸气 → 开篇算膜钱、中段算药钱、结尾取药前三次出现，最后一次按三下没按动，转身去卫生所。
  - 伏笔：周建新条码贴纸卷「鲁NS-2025-XXX」、扫码枪「滴」声、GPS「捕获卫星」 → 每采样必有组合动作，老葛十九瓶倒袋贴码扫码全程盯着「瓶变空、袋变鼓、码响了」。
  - 伏笔：村头老槐树下废旧农药瓶回收箱锈穿底、风吹空空如也、锈洞直径三厘米 → 中段老葛路过曾瞥见，结尾成「归档」终点。
  - 伏笔：老葛口头禅「等雨」/「数得清」/「喉咙响」 → 结尾不回头走时未说一句，风吹锈洞白膜抖动，像在呼吸又像在等下一场雨。
- 章末钩子：锈洞里那片印着半个「程」字的白膜，被风抖动了一下，像在呼吸，又像在等下一场雨。老葛脚步声在垄沟里渐远，没回头。窗台上十九个空位落满灰尘，技术员的条码贴纸卷还在采样箱弹力绳上转着圈。
