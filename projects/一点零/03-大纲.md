# 全书大纲
## 故事线概览（200字内）
视力筛查单上“右眼0.4”折叠成方块塞进工装口袋，何秀兰在收银枪“嘀嘀”声与房贷缺口里，花两千二百六买“度数清零”眼贴。私人视力表“提升两行”，学校筛查单仍是0.4。维权调解室里，保证书“不再追究”栏前笔尖悬停，她拒签拿回半款，带着儿子和那张筛查单走进“明视眼镜”。验光仪“咔咔”翻镜，试戴架架上鼻梁，她掏出手机对准验光单拍照，发给微信里的“王姐”，发给电话那头的老赵。验光师问配哪副，她指着儿子鼻梁上那副试戴架：“就这副，别换了。”

## 第1章 零点四
- **场景（地点与时间）**：
  1. 永兴市华联超市收银台/员工通道（秋季开学次周，晨班 7:00-15:00）；
  2. 永兴市眼科医院走廊/诊室/缴费大厅（同周周六上午）；
  3. 何秀兰出租屋客厅/卫生间（连续三周夜晚）；
  4. 永兴市市场监管所调解室（一个月后工作日午前）；
  5. “明视眼镜”验光室/挑架区（调解当天下午）。
  时间跨度约 40 天，季节从初秋入深秋，温度从 28℃ 降至 14℃。

- **本章目标**：
  何秀兰想用可控的金钱（2260 元眼贴 / 300 元普通镜 / 8000 元离焦镜）买回儿子“不可逆”的视力指标“清零”，并在维权受阻时，通过拒签保证书、实地配镜、拍照发送验光单这三个动作，完成从“追指标”到“看清人”的单一转折。

- **核心冲突（三层同步推进）**：
  1. **个人/生理**：筛查单 0.4 与医生“真性近视不可逆”对撞，何秀兰在“八千离焦镜、三百普通镜、两千二眼贴”三个价格锚点间反复换算，儿子小舟瞒病一年（眯眼、抄错、衣角擦镜）的身体拒绝与母亲“指标之爱”硬碰硬。
  2. **社会/制度**：医院把“控制”写成首选消费项，诊所把“家庭护理用品”备案洗白“清零”，平台把流量卖给“王姐”，监管所把“自愿和解”盖章在“扣三百药材费退一半”上——每个环节有章可循，每个环节卡在“举证责任在你”。
  3. **关系/观念**：丈夫老赵电话里“转账五千/你定/风噪呼啸”将关怀外包为现金流；“王姐”语音条吸鼻子结尾、女儿背影图循环复用，把“也是母亲”当护身符；医生敲键盘不抬头、验光师翻镜片不问价，把专业壁垒立在对话另一端。何秀兰试图用“看得清（数值）”填补“被看见（关系）”，发现指标归零了，人还在原地。

- **转折/结果（唯一转折，源自何秀兰自身选择）**：
  调解室里，李所长推过《调解协议书》兼《保证书》——“扣 300 元药材费，退 1130 元，签字按手印承诺不再追究、不再声张，钱明天到账”。何秀兰右手食指在复写纸粗糙面上做扫码“滑动”动作（C3），算清：买 2260，退 1130，亏 1130＋300 药材费＋一个月工资的三分之一。王姐微信弹出语音：“阿姨签了就到账，别耽误大家”。何秀兰盯着“不再追究”四字，笔尖划破复写纸（C10），**不签**。推回笔：“我不签，退一半算数吗？”李所长盖章“调解终结”，现场转账 1130 元。何秀兰没去派出所，没发朋友圈，拉着小舟走进路边“明视眼镜”。验光师小周翻转综合验光仪“咔咔”落位，小舟戴上试戴架眨眨眼，第一动作摘下用左肩校服衣角横擦两下（C4）再戴上，嘟囔“压鼻梁”（C5）。何秀兰从包里掏出手机，对准验光单（右眼 -1.25D 矫正至 1.0，C10）拍一张，发给“王姐”，发给老赵。小周问：“配哪副？”何秀兰没看价签，指着儿子鼻梁上那副试戴架：“就这副，别换了。”

- **信息与世界观揭示（滴灌式，零说明文）**：
  - **超市收银台**：扫码枪“嘀嘀”节奏=何秀兰心跳/计算节奏；工装口袋筛查单纸边起毛、汗水蹭透（C1）；广播“收银员五号”响起指尖发白。
  - **医院诊室**：赵医生敲键盘不抬头，屏幕上“离焦镜控制度数增长、普通镜只能看清黑板”两行字；何秀兰在脑内把 8000 换算成 2000 个午饭盒（C2）。
  - **微信/眼贴**：铝箔袋撕开薄荷脑味冲鼻腔，贴上小舟眼睑他哆嗦一下；王姐语音条结尾 0.3 秒吸鼻子声（C7）；朋友圈/聊天/售后群女儿背影图同一张蓝色校服马尾右眼花形贴（C8）；文字承诺“不清零全额退款绝不赖账诊所背书有资质阿姨放心”无标点长串（C9）。
  - **家中夜晚**：小舟书包侧袋奥特曼卡包里三角折验光单（右眼 -1.50D，C6）；何秀兰床底纸箱里去年双十一退掉的离焦镜试戴架退款单扣 50 元手续费（秘密）。
  - **调解室**：李所长盖章“调解结案”声闷响；复写纸划破指尖粗糙感；王姐微信红点跳动；老赵转账 5000 到账短信震动。
  - **眼镜店**：验光仪翻镜片“咔咔”金属撞击声；试戴架鼻托压红印；验光单上“R -1.25D / L 0.00D 矫正视力 1.0”（C10）；手机屏幕亮起两条已发送绿勾。

- **伏笔/回收**：
  - 伏笔：开场筛查单折成方块塞口袋（C1）→ 回收：眼镜店验光师要求存档，何秀兰犹豫两秒递出。
  - 伏笔：何秀兰只问价不问效（C2）→ 回收：面对医生/王姐/验光师首句皆为“多少钱/能不能报销/退款怎么算”，结尾指试戴架未看价签。
  - 伏笔：小舟衣角擦镜片（C4）、只说“不疼/压鼻梁”（C5）、验光单三角折法（C6）→ 回收：眼镜店全流程复现，结尾第一次眨眼说“能看见黑板了”随即补句“压鼻梁”。
  - 伏笔：王姐语音吸鼻子（C7）、女儿背影图重复（C8）、无标点承诺（C9）→ 回收：调解室何秀兰播放录音/展示截图/展示聊天记录，三件物证钉死话术闭环。
  - 伏笔：何秀兰指尖扫码滑动算账（C3）→ 回收：调解室算退款、眼镜店核对度数、发照片前长按选择“发送”三次同一动作。
  - 伏笔：床底退掉的离焦镜退款单扣 50 元（秘密）→ 回收：结尾“不看价签”暗含一次被扣手续费的肌肉记忆。
  - 伏笔：老赵电话“风噪/行行行/寄五千”→ 回收：调解室到账短信震动，何秀兰对黑屏说“你也不问买啥”，结尾照片发给老赵无回复。

- **章末钩子（全书收尾）**：
  验光师小周拿着单据问：“配哪副？”何秀兰没看价签，指着儿子鼻梁上那副试戴架：“就这副，别换了。” 小舟擦了擦鼻梁红印，眨眨眼：“能看见黑板了。压鼻梁。” 手机屏幕亮着，两条绿勾在“王姐”“老赵”对话框里并排。门口秋风卷进一片干叶，扫码枪“嘀嘀”声仿佛还在耳边。
