# 创作概念  

## 一句话卖点  
**在由十几个旋钮决定全球雨线的 2126 年，一名降水仲裁员发现某高原的毫米数被篡改，揭开 2040 年代基线伪造的百年干旱真相，迫使三大集团在气候互毁边缘重新算账。**  

## 故事前提展开  
2126 年，平流层气溶胶注入、轨道反射环、海洋碱化泵组成的「全球恒温器」每转动一度，季风带就随之偏移，降水成为可计量、可交易的配额。《全球配温协定》以 2040 年代的历史基线为锚，将每个行政区的年均毫米数锁死在档案里。降水仲裁员林檀例行核验青藏高原边缘的 112 号水文站，读数比档案高出 3.7 毫米——误差带内本应为零。她顺着数据痕迹追溯到 2043 年的基线修订会议，发现某国代表在签字时把原本 210 毫米的基线改成 165 毫米，导致该国及其下游 4 亿人口在随后八十年里被合法「少分」雨水。三大集团正准备用同一份伪造基线启动新一轮配温分配，林檀必须在仲裁庭的签字仪式前，把被篡改的数字还原到雨线两侧的土壤里。  

## 核心冲突  

| 层级 | 冲突描述 |
|------|----------|
| **个人** | 林檀右膝旧伤（十年前一次仲裁导致好友所在区绝收）让她每次跨过雨线都伴随膝盖深处的钝痛；她必须在职业性克制与替旧友讨回公道的冲动之间抉择。 |
| **社会** | 未计数者聚居在「干区」边缘，靠偷采冷凝水维生；一旦基线被证伪，他们的生存配额将被重新计算，引发跨区暴动与保险联合体的索赔风暴。 |
| **观念** | 「雨线是技术中立的物理线」与「雨线是政治权力的书写工具」的对抗；仲裁员的签字手势既是技术确认，也是权力背书，思想实验落点在于：**当配额的来源被证明是谎言，配额本身还拥有合法性吗？** |

## 主题与承载的思想实验  
**思想实验**：「如果全球气温由十几个旋钮共同控制，每一次转动都在重新划分生存资源，那么**配额的合法性究竟来自物理测量，还是来自签署基线的那支笔**？」  
- 落位：把抽象的「公地悲剧」转化为 **「历史基线可被篡改 → 百年干旱合法化 → 当下配额分配沿用谎言」** 的三级因果链。  
- 代价承担者：被少分雨水的高原牧民、被迫迁徙的未计数者、为维持现状而签字的仲裁员。  
- 三幕升级：个人核验 → 社会暴动与保险违约 → 三大集团在轨道冷轨上演「气候互毁」博弈。  

## 子类型与基调  
- **主类型**：硬科幻（工程约束、气候物理、轨道热力学全程自洽）  
- **副类型**：近未来政治惊悚（扳手政治、法域套利、保险治理）  
- **基调**：克制、具象、冷峻中带温度；开篇即以雨线两侧的湿度差、金属仪表的震动、陈旧档案库的霉味为感官锚点。  

## 主角简述  
**林檀，42 岁，降水仲裁员（C1‑C10 见下）。**  
- 身份：持有《全球配温协定》授权的「毫米级签字权」，随身携带经校准的 **W‑12 便携式激光雨滴谱仪**。  
- 欲望：把被篡改的基线还原到雨线两侧的土壤里，让好友的墓碑不再被干旱吞噬。  
- 缺陷：右膝陈旧撕裂，每次跨越雨线都需先吞下一片止痛贴；职业性克制让她习惯用「数据不说话」掩饰愤怒。  

## 结局走向  
林檀在仲裁庭直播签字前，利用轨道清道夫提供的 **冷轨散热窗口**（W7）将伪造基线的原始磁带上传至全网碳账本（W8），触发「气候互毁」条款的自动熔断。三大集团被迫在轨道反射环上暂停转动，改由 **「未计数者代表团」** 与 **「档案产业」** 共同重新跑 2040‑2050 年的实测数据，生成新的动态基线。雨线首次出现 **「浮动带」**，配额按实测毫米动态分配，林檀的签字手势从「确认」变为「见证」。  

## 创新点（与常见套路的区别）  
| 常见套路 | 本作差异化处理 |
|----------|----------------|
| **「醒来发现真相」**（冬眠/失忆） | 主角从未失忆，真相藏在 **可追溯的档案版本号** 里，揭露过程是 **工程级审计** 而非记忆闪回。 |
| **「AI/算法失控」** | 无超级智能，核心冲突来自 **人类在签字时的微小篡改** 与 **制度化的惯性**。 |
| **「末日倒计时」** | 倒计时不是小行星撞击，而是 **下一轮配温旋钮转动的 48 小时窗口**；解法是 **重写基线**，而非逃离地球。 |
| **「英雄单枪匹马」** | 关键节点依赖 **轨道清道夫、未计数者网络、档案产业** 三方的 **制度化协作**，每方都有各自利益账本。 |
| **「雨线即国界」** | 雨线被写成 **可编程的毫米带**，并随轨道冷轨调度实时漂移，不再是静止地图线。 |

## 硬性设定铁律 W1‑W12  

| 编号 | 设定名称 | 核心内容（具象化） |
|------|----------|--------------------|
| **W1** | **恒温器授权链** | 十五个旋钮由「三大集团」各派两名工程师、条约机构派一名监察员、保险联合体派一名精算师共同持钥；每转动 0.1℃ 需三方双盲签字，日志写入区块链式碳账本（W8）。 |
| **W2** | **雨线定义与仲裁程序** | 雨线 = 某纬度带内年均降水 **±0.5 mm** 等值线；仲裁员每季以 **W‑12 便携谱仪** 在 3 个基准站同步读数，误差带超 0.3 mm 即触发「偷雨」调查。 |
| **W3** | **配额折算为实际毫米** | 基线毫米 × 区域面积 × 0.87（蒸发损耗系数）= 年配额立方米；再按人口、作物系数二次分配，最终以 **「额度卡」**（可编程额度）发放至户。 |
| **W4** | **偷雨判定与惩罚** | 非法反射环、未申报碱化泵、篡改云图均判定为「偷雨」；初犯冻结该区 3 年额度，再犯剥夺轨道冷轨槽位（W7）并由保险联合体追偿。 |
| **W5** | **未计数者法理地位** | 无国籍登记者被标记为 **「U‑Class」**，仅享有「最低生存水配额」（每日 2 L），不得参与配额交易，但可通过「档案产业」申请补录历史基线数据。 |
| **W6** | **轨道冷轨与碎片归属** | 轨道 400‑800 km 带为「冷轨」，每槽位散热上限 2 MW，由条约机构拍卖；碎片撞击责任归属最近一次「清道夫作业」的承包商，赔偿以算力本位结算。 |
| **W7** | **三大集团否决权与气候互毁触发条件** | 任一集团若在 48 h 内连续两次否决旋钮转动，自动触发「气候互毁」：反射环全开、碱化泵全停，全球降水瞬时偏移 >15 %，视为最高级别制裁。 |
| **W8** | **碳账本与额度兑换** | 所有排放、吸收、雨线偏移量以 **「碳‑米」** 双单位记账；额度可在「法域套利平台」跨国流转，汇率由保险联合体每日挂牌。 |
| **W9** | **聚变站点与能源阶梯** | 11 座聚变电站（代号 F‑01 至 F‑11）输出功率按政治权重分配；顶层集团享 100 % 基载，次级 60 %，平台城邦 30 %，未计数者 0 %（依靠冷凝水）。 |
| **W10** | **管理性撤退评级** | 沿海城市分「保全/延缓/放弃」三级；放弃区自动切断电网、供水，仅保留「朝圣巴士」通道（见日常细节）。 |
| **W11** | **轨道数据中心与算力本位** | 轨道数据中心吞吐全球 52 % 算力，冷却依赖冷轨；算力租赁以 **「秒·FLOPS」** 计价，直接挂钩碳账本额度。 |
| **W12** | **仲裁员仪表与签字手势** | 标配 **W‑12 激光雨滴谱仪**（分辨率 0.01 mm）、**生物指纹笔**（指纹+心率双重认证）；签字时须在屏幕上划出 **「∟」** 形手势，代表「确认并不可逆」。 |

## 日常细节清单（每项正文至少出现一次）  

1. **仲裁员仪表毫米读数与误差带** —— 林檀把 W‑12 对准雨滴，屏幕闪烁 **112.3 mm ±0.12**，指尖感受到探头微振。  
2. **雨线两侧土壤与空气差别** —— 跨过雨线瞬间，鼻腔从干燥的石英尘味转为湿腻的青苔气，脚下土壤从沙砾变为粘性红壤。  
3. **配温区通行证件** —— 她的「额度卡」在检查站刷过，全息投影弹出 **「年配额 1 200 mm，剩余 312 mm」**，边框闪烁着保险联合体的蓝色水印。  
4. **被放弃城市朝圣巴士** —— 生锈的磁悬浮巴士在「放弃区」边缘停靠，车厢内挂着「档案产业」的广告：「重访 2035，见证海平面上升的最后一根路灯」。  
5. **一口水多少额度** —— 未计数者聚居点的公共冷凝塔显示：「今日产水 4 L，折合 0.001 额度，需以算力秒数抵扣」。  
6. **未计数者聚居形态** —— 由废弃集装箱拼搭的「干区村」，屋顶铺设薄膜太阳能板，墙面贴着手写的「雨线坐标」与「基线版本号」。  
7. **轨道清道夫班次与风险** —— 清道夫「老陈」在 02:00‑06:00 窗口驾驶 **「拾荒者‑7」** 捕获 3 cm 碎片，舱内温度升至 38 ℃，冷却液报警灯红光闪烁。

## 角色一致性要点 C1‑C10  

| 编号 | 要点 | 正文体现方式 |
|------|------|--------------|
| **C1** | **签字手势固定为「∟」** | 每次仲裁结案，林檀在屏幕上划出直角，手指关节发出轻微咔哒声。 |
| **C2** | **职业性克制：不说「我觉得」，只读数** | 对话中她只回：「读数 112.3，误差 0.12，符合 W2。」 |
| **C3** | **右膝旧伤随雨线跨越加剧** | 每次跨雨线前先贴一片透皮止痛贴，膝盖内侧隐隐作响。 |
| **C4** | **对「未计数者」保持距离却暗存愧疚** | 看到干区村儿童喝冷凝水时，她会把随身的额度卡多留 0.5 mm。 |
| **C5** | **信任「档案产业」而非三大集团** | 关键证据只交给档案馆的老馆长，拒绝上传至集团服务器。 |
| **C6** | **习惯用「数据不说话」掩饰情绪** | 面对上级施压，她只重复：「W‑12 显示 112.3 mm。」 |
| **C7** | **对轨道清道夫有私人欠情** | 老陈曾在碎片风暴中护送她撤离，她会在清道夫班次表上标记「优先通行」。 |
| **C8** | **拒绝使用「长寿订阅」延缓衰老** | 她的体检报告上「订阅状态：未开通」，理由：「不想把膝盖的痛交给算法」。 |
| **C9** | **口头禅：「毫米不说谎」** | 在任何争执中，她以此句终结话题。 |
| **C10** | **最终选择「见证」而非「裁决」** | 结局签字时手势从「∟」变为「✓」，语义从「确认」转为「见证」。 |
